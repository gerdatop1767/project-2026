# Практика к заданию 5

Найди неверно употреблённое слово и замени паронимом.
1. Он надел младшего брата тёплую куртку.
2. Это был экономический автомобиль: он расходовал мало топлива.
3. Комиссия представила участникам зал для репетиций.
4. В письме содержалось благодарное сообщение организаторам.
5. Научная статья оказалась очень эффектной: она позволила сократить расходы.

## Ответы
1. **одел** — одеть кого, надеть что.
2. **экономичный** — требующий небольших затрат.
3. **предоставила** — дала в распоряжение.
4. **благодарственное** — выражающее благодарность.
5. **эффективной** — дающей результат; эффектная производит впечатление.
