# Практика — задание 26

Выбери подходящее средство связи.

1. «Начался сильный дождь. ___ прогулку пришлось отложить». (поэтому / однако)
2. «На полке стояла старая книга. ___ принадлежала дедушке». (Она / Однако)
3. «Первый способ оказался дорогим. ___ второй был значительно дешевле». (Напротив / Затем)
4. «Сначала нужно собрать данные. ___ следует проверить их достоверность». (Затем / Потому что)

## Ответы
1. **Поэтому** — следствие.
2. **Она** — местоименная связь с «книга».
3. **Напротив** — противопоставление/сопоставление.
4. **Затем** — последовательность действий.
