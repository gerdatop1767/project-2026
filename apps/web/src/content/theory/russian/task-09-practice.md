# Практика к заданию 9

Восстанови буквы и определи правило.
1. соб..рать, выд..рать, зам..рать
2. изл..гать, предл..жение, пол..жить
3. р..стение, выр..щенный, зар..сли
4. прим..рить (пальто), прим..рить (друзей), зам..реть
5. ш..пот, ж..лтый, ч..рный

## Ответы
1. собирать, выдирать, замирать — **И**, чередование зависит от суффикса -а-.
2. излагать, предложение, положить — буквы различаются, ряд не подходит.
3. растение, выращенный, заросли — буквы различаются, ряд не подходит.
4. примерить пальто, примирить друзей, замереть — буквы различаются; смысл важен.
5. шёпот, жёлтый, чёрный — **Ё**, проверка через однокоренные слова с Е.
