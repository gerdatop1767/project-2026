# Практика — задание 23

Текст: «После нескольких неудачных попыток исследователь изменил способ наблюдения. Новые данные не сразу объяснили причину явления, однако помогли исключить две прежние гипотезы. Лишь после повторного опыта команда сформулировала осторожный вывод».

Верно ли?

1. Исследователь изменил метод после неудач.
2. Новые данные сразу полностью объяснили явление.
3. Данные помогли исключить две гипотезы.
4. Команда сделала окончательный вывод до повторного опыта.
5. В тексте показан постепенный ход исследования.

## Ответы
1. **Да.** Это сказано прямо.
2. **Нет.** Указано «не сразу»; данные помогли исключить гипотезы, а не полностью объяснить явление.
3. **Да.** Прямое соответствие тексту.
4. **Нет.** Вывод сформулировали после повторного опыта и назвали осторожным.
5. **Да.** Описана последовательность попыток и уточнения метода.
