# Практика к заданию 7

Исправь ошибку.
1. В соревнованиях участвовали опытные инженера.
2. По приезду в город мы отправились в музей.
3. Она купила более красивейшую вазу.
4. Согласно расписания поезд отправляется в семь.
5. Мой день рождения прошёл спокойно.

## Ответы
1. инженеры.
2. по приезде.
3. более красивую вазу / красивейшую вазу.
4. согласно расписанию.
5. Ошибки нет.
