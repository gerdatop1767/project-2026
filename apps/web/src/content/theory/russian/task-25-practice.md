# Практика — задание 25

Определи явление.

1. «У него золотые руки».
2. «Адресат получил письмо, а адресант отправил его».
3. «Он держал язык за зубами».
4. «Лук лежал рядом с луком для стрельбы».

## Ответы
1. **Переносное значение**: умелые руки.
2. **Паронимы**: адресат — получатель, адресант — отправитель.
3. **Фразеологизм**: молчал, не разглашал.
4. **Омонимы**: лук-растение и лук-оружие.
