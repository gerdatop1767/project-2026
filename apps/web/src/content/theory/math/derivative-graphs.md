# Производная и первообразная

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — задание №8, часть 1, 1 балл. Проверяется: функция, экстремум, наибольшее и наименьшее значения на промежутке, производная и первообразная, уравнение касательной, исследование функций, площади фигур с помощью интеграла.
- **Старый сборник Ященко-2027** — задание №9.

Почти всегда в №8 дан **рисунок**: график функции, график её производной или касательная. Ответ получают, читая рисунок по правилам ниже.

## 1. Геометрический смысл производной

Производная в точке $x_0$ равна угловому коэффициенту касательной к графику в этой точке:

$$f'(x_0) = k = \operatorname{tg}\alpha$$

где $\alpha$ — угол между касательной и положительным направлением оси $Ox$.

![[deriv-tangent]] $f(x) = \frac{x^2}4$. Касательная в точке $x_0 = 2$ — прямая $y = x - 1$, её угловой коэффициент равен $f'(2) = 1$.

> [!example] Касательная по двум точкам
> Касательная проходит через точки $(1; 2)$ и $(5; 10)$. Угловой коэффициент: $k = \frac{10 - 2}{5 - 1} = 2$, значит $f'(x_0) = 2$.

> [!remember] Знак по наклону
> Касательная поднимается слева направо — производная положительна. Опускается — отрицательна. Горизонтальна — производная равна нулю.

Уравнение касательной:

$$y = f(x_0) + f'(x_0)(x - x_0)$$

Для $f(x) = x^2$ в точке $x_0 = 3$: $y = 9 + 6(x - 3) = 6x - 9$.

## 2. Что видно по графику самой функции $f$

| На графике $f$ | Значит |
|---|---|
| функция возрастает | $f' > 0$ |
| функция убывает | $f' < 0$ |
| вершина «горки» или «ямки» (гладкая) | $f' = 0$, это точка экстремума |
| касательная параллельна прямой $y = kx + b$ | $f'(x_0) = k$ |

## 3. Что видно по графику производной $f'$

Это **другая** картинка: здесь высота графика — значение производной, а не функции.

![[deriv-signs]] График $f'(x) = \frac{(x + 2)(x - 1)(x - 3)}{4}$: нули $-2$, 1 и 3.

| На графике $f'$ | Значит для $f$ |
|---|---|
| график выше оси $Ox$ | $f$ возрастает |
| график ниже оси $Ox$ | $f$ убывает |
| пересечение оси «снизу вверх» (минус → плюс) | точка **минимума** $f$ |
| пересечение оси «сверху вниз» (плюс → минус) | точка **максимума** $f$ |
| касание оси без смены знака | экстремума нет |

На рисунке выше у $f$ минимумы в точках $-2$ и 3, а максимум в точке 1.

> [!mistake] Перепутали график функции и производной
> Перед ответом проверь подпись: $y = f(x)$ или $y = f'(x)$. Точки экстремума $f$ на графике производной — это **нули** производной со сменой знака, а не её вершины.

## 4. Физический смысл

Если $x(t)$ — координата точки в момент $t$, то скорость $v(t) = x'(t)$, а ускорение $a(t) = v'(t)$.

> [!example] Скорость
> $x(t) = \frac{t^3}{3} - 2t^2 + 3t$. Тогда $v(t) = t^2 - 4t + 3$, при $t = 4$ скорость $16 - 16 + 3 = 3$.

## 5. Таблица производных

| Функция | Производная |
|---|---|
| $C$ | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\sqrt x$ | $\dfrac{1}{2\sqrt x}$ |
| $e^x$, $\ a^x$ | $e^x$, $\ a^x\ln a$ |
| $\ln x$, $\ \log_a x$ | $\dfrac1x$, $\ \dfrac1{x\ln a}$ |
| $\sin x$, $\ \cos x$ | $\cos x$, $\ -\sin x$ |

Правила: $(u \pm v)' = u' \pm v'$, $\ (uv)' = u'v + uv'$, $\ \left(\frac uv\right)' = \frac{u'v - uv'}{v^2}$, $\ \big(f(g(x))\big)' = f'(g(x))\cdot g'(x)$.

## 6. Первообразная и площадь

$F$ — первообразная для $f$, если $F'(x) = f(x)$. Площадь под графиком положительной функции на отрезке $[a; b]$:

$$S = \int_a^b f(x)\,dx = F(b) - F(a)$$

> [!example] Площадь
> Площадь под графиком $f(x) = 2x$ на $[1; 3]$: $F(x) = x^2$, $S = 9 - 1 = 8$.

Частая задача по графику первообразной: точки, где $f(x) = 0$, — это точки, где касательная к графику $F$ горизонтальна.

## 7. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Прочитай подпись графика: функция, производная или первообразная?
> 2. Нужно значение производной — найди касательную и посчитай $k = \frac{\Delta y}{\Delta x}$ по двум точкам на клетках.
> 3. Нужны промежутки и экстремумы — смотри на знак $f'$ (по графику $f'$) или на рост и спад (по графику $f$).
> 4. Считай точки только на указанном в условии отрезке.

## 8. Типичные ошибки

> [!mistake] Знак углового коэффициента
> Если касательная идёт вниз, производная **отрицательна**, даже если все её точки выше оси $Ox$.

> [!mistake] Точки вне отрезка
> «Сколько точек экстремума на отрезке $[-3; 4]$» — считай только точки внутри этого отрезка.

## 9. Потренируйся

1. Касательная к графику $f$ в точке $x_0$ проходит через $(0; -1)$ и $(4; 7)$. Найди $f'(x_0)$.
2. Точка движется по закону $x(t) = t^2 + 3t$. Найди скорость в момент $t = 5$.
3. Найди площадь под графиком $f(x) = 3x^2$ на отрезке $[0; 2]$.

**Ответы.**
1. $\frac{7 - (-1)}{4 - 0} = 2$.
2. $v = 2t + 3 = 13$.
3. $F(x) = x^3$, $S = 8 - 0 = 8$.
