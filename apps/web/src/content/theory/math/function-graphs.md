# Графики функций

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — задание №11, часть 1, 1 балл. Проверяется: умение выражать формулами зависимости между величинами, использовать свойства и графики функций для решения уравнений.
- **Старый сборник Ященко-2027** — задание №12.

Обычно на рисунке график функции известного вида, проходящий через узлы сетки. Нужно восстановить формулу по точкам и посчитать значение в другой точке или найти точку пересечения.

## 1. Как читать график

- Ищи точки, которые лежат **точно в узлах** клеток: их координаты — целые числа.
- Каждый неизвестный параметр формулы — одна точка. Для прямой нужны две точки, для параболы — вершина и ещё одна точка (или три точки).

## 2. Основные семейства

| Вид | Формула | Что видно на графике |
|---|---|---|
| Прямая | $y = kx + b$ | $b$ — точка пересечения с $Oy$; $k = \frac{\Delta y}{\Delta x}$ |
| Парабола | $y = a(x - x_0)^2 + y_0$ | вершина $(x_0; y_0)$; $a > 0$ — ветви вверх |
| Гипербола | $y = \frac{k}{x - a} + b$ | асимптоты $x = a$ и $y = b$ |
| Корень | $y = a\sqrt{x - x_0} + y_0$ | начало графика в точке $(x_0; y_0)$ |
| Показательная | $y = a^x + b$ | проходит через $(0; 1 + b)$, асимптота $y = b$ |
| Логарифмическая | $y = \log_a(x - x_0) + b$ | асимптота $x = x_0$, проходит через $(x_0 + 1; b)$ |
| Синусоида | $y = A\sin(\omega x) + B$ | $A$ — размах от средней линии $y = B$ |

## 3. Прямая

> [!example] Две точки
> Прямая проходит через $(-1; 3)$ и $(2; -3)$. Тогда $k = \frac{-3 - 3}{2 - (-1)} = -2$, и из $3 = -2\cdot(-1) + b$ получаем $b = 1$. Значит $f(x) = -2x + 1$, $f(-4) = 9$.

## 4. Парабола

![[graph-parabola-vertex]] Вершина $(1; -4)$, парабола проходит через $(3; 0)$.

> [!example] Через вершину
> $y = a(x - 1)^2 - 4$. Подставим $(3; 0)$: $a\cdot4 - 4 = 0$, $a = 1$. Значит $f(x) = (x - 1)^2 - 4$, $f(5) = 16 - 4 = 12$.

> [!remember] Вершина через коэффициенты
> Для $y = ax^2 + bx + c$ абсцисса вершины $x_0 = -\frac{b}{2a}$, а $c$ — точка пересечения с осью $Oy$.

## 5. Гипербола, показательная, логарифмическая

> [!example] Гипербола
> Асимптота $y = 2$, график проходит через $(1; 5)$: $y = \frac kx + 2$, $5 = k + 2$, $k = 3$. Тогда $f(6) = \frac36 + 2 = 2{,}5$.

> [!example] Показательная
> $y = a^x$ проходит через $(2; 9)$: $a^2 = 9$, $a = 3$ (основание положительно). Тогда $f(3) = 27$.

> [!example] Логарифмическая
> $y = \log_a x$ проходит через $(8; 3)$: $a^3 = 8$, $a = 2$. При каком $x$ значение равно 5? $\log_2 x = 5 \Rightarrow x = 32$.

## 6. Точки пересечения графиков

Абсциссы точек пересечения — корни уравнения $f(x) = g(x)$.

> [!example] Прямая и парабола
> $f(x) = 2x + 1$ и $g(x) = x^2 - 2$ пересекаются в точке $(-1; -1)$ и ещё одной. $x^2 - 2 = 2x + 1 \iff x^2 - 2x - 3 = 0$, корни $-1$ и 3. Вторая точка $(3; 7)$, её ордината 7.

## 7. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Определи вид функции по форме графика (прямая, парабола, гипербола…).
> 2. Найди на рисунке точки в узлах сетки — по одной на каждый неизвестный параметр.
> 3. Подставь точки в формулу и найди параметры.
> 4. Вычисли то, что спрашивают, и проверь по рисунку, что ответ правдоподобен.

## 8. Типичные ошибки

> [!mistake] Точка не в узле
> Брать точку «на глаз» между клетками нельзя: параметры получатся неточными. Ищи точки строго в узлах.

> [!mistake] Сдвиг не в ту сторону
> График $y = (x - 1)^2$ сдвинут **вправо** на 1, а не влево.

## 9. Потренируйся

1. Прямая проходит через $(0; -2)$ и $(3; 4)$. Найди $f(5)$.
2. Парабола $y = a(x + 2)^2 + 1$ проходит через $(0; 9)$. Найди $a$.
3. $y = \log_a x$ проходит через $(9; 2)$. Найди $f(81)$.

**Ответы.**
1. $k = 2$, $b = -2$, $f(5) = 8$.
2. $4a + 1 = 9$, $a = 2$.
3. $a = 3$, $f(81) = 4$.
