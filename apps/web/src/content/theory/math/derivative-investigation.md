# Наибольшее и наименьшее значение функции

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — задание №12, часть 1, 1 балл. Проверяется: экстремум функции, наибольшее и наименьшее значения на промежутке, производные элементарных функций, исследование функции с помощью производной.
- **Старый сборник Ященко-2027** — отдельного номера нет: в проекте КИМ, по которому составлен сборник, это входило в №9.

В отличие от №8, рисунка нет: функция задана формулой, и её нужно исследовать самому.

## 1. Точки экстремума

Точка $x_0$ — точка **максимума**, если рядом с ней значения функции меньше $f(x_0)$; **минимума** — если больше.

Как найти:

1. Найди $f'(x)$.
2. Реши уравнение $f'(x) = 0$ (и отметь точки, где производной нет).
3. Определи знак $f'$ на промежутках между найденными точками.
4. Смена знака «$+$ → $-$» — максимум, «$-$ → $+$» — минимум, без смены знака — экстремума нет.

![[extremum-cubic]] $f(x) = x^3 - 3x^2 + 2$: $f'(x) = 3x^2 - 6x = 3x(x - 2)$. Максимум в точке 0, минимум в точке 2.

> [!remember] Точка экстремума — это $x$, а не $y$
> «Найдите точку максимума» — ответ 0 (абсцисса). «Найдите наибольшее значение» — ответ $f(\dots)$, значение функции.

## 2. Наибольшее и наименьшее значения на отрезке

Непрерывная на отрезке $[a; b]$ функция достигает наибольшего и наименьшего значений либо на концах отрезка, либо в точках экстремума внутри него.

> [!example] Кубическая функция
> $f(x) = x^3 - 3x^2 + 2$ на $[-1; 4]$. Критические точки внутри: 0 и 2.
> $f(-1) = -2$, $f(0) = 2$, $f(2) = -2$, $f(4) = 18$.
> Наибольшее значение 18 (на конце отрезка), наименьшее $-2$.

Если на отрезке ровно одна точка экстремума и это максимум, то наибольшее значение — в ней. Тогда концы можно не считать — так задачи часто и устроены.

## 3. Типы функций в №12

### С экспонентой

Производная произведения: $\big((x - 3)e^{x - 2}\big)' = e^{x - 2} + (x - 3)e^{x - 2} = e^{x - 2}(x - 2)$.

$e^{x - 2} > 0$ всегда, поэтому знак производной — знак $(x - 2)$. Минимум в точке 2, $f(2) = (2 - 3)e^0 = -1$.

### С логарифмом

$y = 5\ln(x + 5) - 5x$ на $[-4{,}5; 0]$: $y' = \frac{5}{x + 5} - 5 = 0 \Rightarrow x = -4$. Знак меняется с «$+$» на «$-$» — максимум. $y(-4) = 5\ln1 + 20 = 20$.

### Тригонометрические

$y = 9\cos x + 14x + 8$ на $\left[0; \frac{3\pi}{2}\right]$: $y' = -9\sin x + 14 > 0$ всегда (так как $9\sin x \le 9 < 14$). Функция возрастает, наименьшее значение на левом конце: $y(0) = 9 + 0 + 8 = 17$.

> [!tip] Когда считать не надо
> Если производная не меняет знак, функция монотонна — экстремум на концах отрезка. Так устроено большинство «тригонометрических» №12: значение в «некрасивой» точке ($\pi$ в ответе) ЕГЭ не требует.

### С корнем

$y = x\sqrt x - 3x + 1$ на $[1; 9]$: $y = x^{3/2} - 3x + 1$, $\ y' = \frac32\sqrt x - 3 = 0 \Rightarrow x = 4$.
$y(1) = -1$, $y(4) = 8 - 12 + 1 = -3$, $y(9) = 27 - 27 + 1 = 1$. Наименьшее значение $-3$.

## 4. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Найди область определения (логарифм, корень, знаменатель).
> 2. Найди $f'$ и её нули; оставь только те, что лежат в нужном промежутке.
> 3. Расставь знаки производной.
> 4. Ответь на вопрос: точка экстремума ($x$) или значение ($y$)? На отрезке — сравни значения в критических точках и, при необходимости, на концах.

## 5. Типичные ошибки

> [!mistake] Значение вместо точки
> В «точке максимума» ответ — абсцисса, а не значение функции.

> [!mistake] Нуль производной без смены знака
> $f(x) = x^3$: $f'(0) = 0$, но экстремума нет — производная не меняет знак.

> [!mistake] Нуль производной за пределами отрезка
> Если корень $f'$ лежит вне отрезка, его не учитывают: смотрят только на концы.

## 6. Потренируйся

1. Найди точку максимума функции $y = x^3 - 3x^2 + 2$.
2. Найди наименьшее значение функции $y = (x - 3)e^{x - 2}$ на отрезке $[1; 3]$.
3. Найди наименьшее значение функции $y = x\sqrt x - 3x + 1$ на отрезке $[1; 9]$.

**Ответы.**
1. 0.
2. $-1$ (в точке минимума $x = 2$; на концах $y(1) = -2e^{-1} \approx -0{,}74$ и $y(3) = 0$ больше).
3. $-3$.
