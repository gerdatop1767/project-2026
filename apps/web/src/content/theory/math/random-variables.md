# Случайные величины

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — отдельного номера нет. Случайная величина, распределение, математическое ожидание, дисперсия и стандартное отклонение входят в требование 8 кодификатора ФИПИ, которое проверяется заданиями №4–5 (теория вероятностей). В демоверсиях задач на эту тему нет.
- **Старый сборник Ященко-2027** (составлен по проекту КИМ августа 2026 года) — задание №6, часть 1, 1 балл.

> [!tip] Как читать эту тему
> Сначала разберись с таблицей распределения (§1) — на ней держится всё остальное. Формулы §2–3 сводятся к одной операции: «умножь значение на вероятность и сложи».

## 1. Случайная величина и её распределение

**Случайная величина** $X$ — это число, которое получается в результате случайного опыта: число орлов при бросках монеты, очки на кости, число попаданий из нескольких выстрелов.

Если значений конечное число, величину задают **таблицей распределения**: какие значения $x_1, x_2, \dots, x_n$ она принимает и с какими вероятностями $p_1, p_2, \dots, p_n$.

| $X$ | $x_1$ | $x_2$ | … | $x_n$ |
|---|---|---|---|---|
| $P$ | $p_1$ | $p_2$ | … | $p_n$ |

> [!remember] Главное свойство таблицы
> Все вероятности неотрицательны, а их сумма равна единице:
> $$p_1 + p_2 + \dots + p_n = 1$$
> Именно так находят «пропущенную» вероятность в таблице.

### Пример: две монеты

Монету бросают два раза, $X$ — число выпавших орлов. Исходы равновозможны: ОО, ОР, РО, РР. Ноль орлов — 1 исход из 4, один орёл — 2 исхода, два орла — 1 исход.

| $X$ | 0 | 1 | 2 |
|---|---|---|---|
| $P$ | $\frac14$ | $\frac12$ | $\frac14$ |

![[rv-two-coins]] Высота столбца — вероятность значения; пунктир — математическое ожидание (см. §2).

## 2. Математическое ожидание

**Математическое ожидание** — «среднее значение» величины при большом числе повторений опыта:

$$E(X) = x_1p_1 + x_2p_2 + \dots + x_np_n$$

Для двух монет: $E(X) = 0\cdot\frac14 + 1\cdot\frac12 + 2\cdot\frac14 = 1$. В среднем выпадает один орёл.

Для игральной кости: $E(X) = (1+2+3+4+5+6)\cdot\frac16 = 3{,}5$. Ожидание не обязано быть одним из значений величины.

![[rv-die]] Все шесть значений равновероятны, поэтому $E(X)$ — ровно посередине.

### Свойства, которые экономят время

- $E(c) = c$ — ожидание постоянной равно ей самой.
- $E(aX + b) = a\,E(X) + b$.
- $E(X + Y) = E(X) + E(Y)$ — **всегда**, даже если величины зависимы.

> [!example] Сумма очков на двух костях
> Не нужно выписывать 36 исходов: $E(X_1 + X_2) = 3{,}5 + 3{,}5 = 7$.

### Число успехов в серии испытаний

Пусть проводится $n$ независимых испытаний, в каждом успех с вероятностью $p$, и $X$ — число успехов. Тогда

$$E(X) = np$$

Почему так: $X$ — сумма $n$ величин «1, если в $i$-м испытании успех, иначе 0», а ожидание каждой из них равно $p$.

## 3. Дисперсия и стандартное отклонение

Ожидание говорит, где «центр». **Дисперсия** — насколько значения разбросаны вокруг него:

$$D(X) = E\big((X - E(X))^2\big) = E(X^2) - \big(E(X)\big)^2$$

**Стандартное отклонение** — корень из дисперсии, оно измеряется в тех же единицах, что и сама величина:

$$\sigma(X) = \sqrt{D(X)}$$

### Как считать по таблице: две монеты

1. $E(X) = 1$ (из §2).
2. $E(X^2) = 0^2\cdot\frac14 + 1^2\cdot\frac12 + 2^2\cdot\frac14 = \frac32$.
3. $D(X) = \frac32 - 1^2 = \frac12$, $\sigma(X) = \sqrt{0{,}5} \approx 0{,}71$.

Для игральной кости: $E(X^2) = \frac{1+4+9+16+25+36}{6} = \frac{91}{6}$, $D(X) = \frac{91}{6} - 3{,}5^2 = \frac{35}{12} \approx 2{,}92$.

### Свойства дисперсии

| Выражение | Чему равно | Комментарий |
|---|---|---|
| $D(c)$ | $0$ | у постоянной нет разброса |
| $D(X + b)$ | $D(X)$ | сдвиг не меняет разброс |
| $D(aX)$ | $a^2D(X)$ | множитель выходит **в квадрате** |
| $D(X + Y)$ | $D(X) + D(Y)$ | **только для независимых** $X$ и $Y$ |
| число успехов в $n$ испытаниях | $np(1-p)$ | следует из строки выше |

> [!mistake] Дисперсия и множитель
> $D(2X) = 4D(X)$, а не $2D(X)$. Зато $\sigma(2X) = 2\sigma(X)$.

## 4. Непрерывные распределения

Кодификатор ФИПИ (требование 8, и в 2026, и в 2027 году) называет также функции распределения и плотности равномерного, показательного и нормального распределений. В демоверсиях таких задач нет, поэтому ниже — только то, что нужно знать для понимания.

**Равномерное на отрезке $[a; b]$.** Вероятность попасть в часть отрезка пропорциональна её длине:

$$P(c \le X \le d) = \frac{d - c}{b - a}, \qquad E(X) = \frac{a+b}{2}, \qquad D(X) = \frac{(b-a)^2}{12}$$

**Показательное с параметром $\lambda > 0$** (время ожидания события):

$$P(X > t) = e^{-\lambda t}, \qquad E(X) = \frac1\lambda$$

**Нормальное с ожиданием $\mu$ и отклонением $\sigma$** — правило «трёх сигм»:

| Отрезок | Вероятность попасть в него |
|---|---|
| $[\mu - \sigma;\ \mu + \sigma]$ | $\approx 0{,}683$ |
| $[\mu - 2\sigma;\ \mu + 2\sigma]$ | $\approx 0{,}954$ |
| $[\mu - 3\sigma;\ \mu + 3\sigma]$ | $\approx 0{,}997$ |

## 5. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Найди в условии величину $X$ и выпиши её значения.
> 2. Составь таблицу распределения; проверь, что сумма вероятностей равна 1.
> 3. Ожидание: «значение × вероятность», сложить. Для суммы величин или серии испытаний — свойства из §2, без перебора.
> 4. Дисперсия: сначала $E(X^2)$, потом $D = E(X^2) - (E(X))^2$. Отклонение — корень.
> 5. Ответ — десятичной дробью, если не сказано иначе.

**Проверь себя перед записью ответа:**
- каждая вероятность лежит между 0 и 1;
- ожидание не меньше наименьшего и не больше наибольшего значения $X$;
- дисперсия неотрицательна, а $\sigma$ — корень из неё, а не она сама.

## 6. Типичные ошибки

> [!mistake] Квадрат ожидания вместо ожидания квадрата
> $E(X^2)$ и $\big(E(X)\big)^2$ — разные числа. Их разность и есть дисперсия.

> [!mistake] Сложение дисперсий зависимых величин
> $D(X + Y) = D(X) + D(Y)$ верно только для независимых величин. Для ожиданий — всегда.

> [!mistake] Ответ «дисперсия», когда просили «отклонение»
> Стандартное отклонение — это $\sqrt{D}$. Перечитай вопрос перед записью ответа.

## 7. Потренируйся

1. Величина $X$ принимает значения 1, 2, 3 с вероятностями $0{,}2$; $0{,}5$; $p$. Найди $p$, $E(X)$, $D(X)$ и $\sigma(X)$.
2. Бросают две игральные кости. Найди математическое ожидание суммы очков.
3. Стрелок делает 4 независимых выстрела, вероятность попадания при каждом $0{,}8$. Найди ожидание, дисперсию и стандартное отклонение числа попаданий.

**Ответы.**
1. $p = 0{,}3$; $E(X) = 2{,}1$; $E(X^2) = 4{,}9$, поэтому $D(X) = 4{,}9 - 2{,}1^2 = 0{,}49$; $\sigma(X) = 0{,}7$.
2. $3{,}5 + 3{,}5 = 7$.
3. $E = 4\cdot0{,}8 = 3{,}2$; $D = 4\cdot0{,}8\cdot0{,}2 = 0{,}64$; $\sigma = 0{,}8$.
