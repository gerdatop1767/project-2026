# Уравнения с развёрнутым решением

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — задание №13, часть 2, 2 балла. Проверяется умение решать уравнения, неравенства и системы с помощью различных приёмов. Задание состоит из двух пунктов: а) решить уравнение; б) найти корни на заданном отрезке.
- **Старый сборник Ященко-2027** — задание №14.

Чаще всего уравнение тригонометрическое. Бывают и смешанные: тригонометрия внутри показательной функции, логарифма или корня.

## 1. Как оценивают

| Баллы | Что должно быть в решении |
|---|---|
| 2 | Обоснованно получены верные ответы в обоих пунктах |
| 1 | Обоснованно получен верный ответ в пункте а **или** ответы неверны из-за вычислительной ошибки, но верна последовательность всех шагов обоих пунктов |
| 0 | Остальные случаи |

> [!exam] Что значит «обоснованно»
> Видно, откуда взялся каждый шаг: какая формула применена, какая сделана замена, почему отброшен корень (не входит в ОДЗ, $|\sin x| \le 1$), каким способом отобраны корни в пункте б.

## 2. Простейшие тригонометрические уравнения

| Уравнение | Решения | Когда есть корни |
|---|---|---|
| $\sin x = a$ | $x = (-1)^k\arcsin a + \pi k$, или две серии $x = \arcsin a + 2\pi k$, $x = \pi - \arcsin a + 2\pi k$ | $\lvert a\rvert \le 1$ |
| $\cos x = a$ | $x = \pm\arccos a + 2\pi k$ | $\lvert a\rvert \le 1$ |
| $\operatorname{tg} x = a$ | $x = \operatorname{arctg} a + \pi k$ | любое $a$ |

Везде $k \in \mathbb{Z}$.

### Частные случаи — их пишут короче

| Уравнение | Решения |
|---|---|
| $\sin x = 0$ | $x = \pi k$ |
| $\sin x = 1$ | $x = \frac{\pi}{2} + 2\pi k$ |
| $\sin x = -1$ | $x = -\frac{\pi}{2} + 2\pi k$ |
| $\cos x = 0$ | $x = \frac{\pi}{2} + \pi k$ |
| $\cos x = 1$ | $x = 2\pi k$ |
| $\cos x = -1$ | $x = \pi + 2\pi k$ |

> [!remember] Аркфункции отрицательного числа
> $\arcsin(-a) = -\arcsin a$, $\operatorname{arctg}(-a) = -\operatorname{arctg} a$, но $\arccos(-a) = \pi - \arccos a$. Например, $\arccos\left(-\frac12\right) = \frac{2\pi}{3}$.

## 3. Формулы, которые понадобятся

**Основное тождество и следствия:**

$$\sin^2 x + \cos^2 x = 1, \qquad 1 + \operatorname{tg}^2 x = \frac{1}{\cos^2 x}$$

**Двойной угол:**

$$\sin 2x = 2\sin x\cos x, \qquad \cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$

**Понижение степени:** $\cos^2 x = \frac{1 + \cos 2x}{2}$, $\sin^2 x = \frac{1 - \cos 2x}{2}$.

**Формулы приведения** — по правилу: если в аргументе $\frac{\pi}{2}$ или $\frac{3\pi}{2}$, функция меняется на «кофункцию» (sin ↔ cos); знак ставится тот, что был у исходной функции в соответствующей четверти. Например, $\sin\left(\frac{3\pi}{2} + x\right) = -\cos x$, $\cos(\pi - x) = -\cos x$.

**Сумма в произведение:**

$$\sin a + \sin b = 2\sin\frac{a + b}{2}\cos\frac{a - b}{2}, \qquad \cos a + \cos b = 2\cos\frac{a + b}{2}\cos\frac{a - b}{2}$$

## 4. Методы решения

### 4.1. Замена: уравнение сводится к квадратному

Если все функции выражаются через одну — $\sin x$, $\cos x$ или $\operatorname{tg} x$, — делаем замену и решаем квадратное уравнение.

> [!example] Пример 1
> а) Решите уравнение $2\cos^2 x + 3\sin x - 3 = 0$.
>
> Заменим $\cos^2 x = 1 - \sin^2 x$: $2 - 2\sin^2 x + 3\sin x - 3 = 0$, то есть $2\sin^2 x - 3\sin x + 1 = 0$.
>
> Пусть $t = \sin x$: $2t^2 - 3t + 1 = 0$, $t = 1$ или $t = \frac12$. Оба значения лежат в $[-1; 1]$.
>
> $\sin x = 1 \Rightarrow x = \frac{\pi}{2} + 2\pi k$; $\ \sin x = \frac12 \Rightarrow x = \frac{\pi}{6} + 2\pi k$ или $x = \frac{5\pi}{6} + 2\pi k$, $k \in \mathbb{Z}$.

### 4.2. Разложение на множители

Произведение равно нулю, когда хотя бы один множитель равен нулю, **а остальные при этом имеют смысл**.

> [!mistake] Нельзя делить на выражение с переменной
> Из $\sin x\cos x = \sin x$ нельзя «сократить» $\sin x$: потеряются корни $x = \pi k$. Правильно: $\sin x(\cos x - 1) = 0$.

### 4.3. Однородные уравнения

Уравнение $a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0$ делят на $\cos^2 x$ и получают квадратное относительно $\operatorname{tg} x$. Делить можно, **только проверив**, что $\cos x = 0$ не даёт корней.

> [!example] Пример 2
> $\sin^2 x - 3\sin x\cos x + 2\cos^2 x = 0$.
>
> Если $\cos x = 0$, то $\sin^2 x = 1$, и левая часть равна $1 \ne 0$. Значит, $\cos x \ne 0$, делим на $\cos^2 x$:
>
> $\operatorname{tg}^2 x - 3\operatorname{tg} x + 2 = 0$, $\operatorname{tg} x = 1$ или $\operatorname{tg} x = 2$.
>
> Ответ: $x = \frac{\pi}{4} + \pi k$, $x = \operatorname{arctg} 2 + \pi k$, $k \in \mathbb{Z}$.

### 4.4. Уравнения с ОДЗ

Если в уравнении есть дробь, корень чётной степени, логарифм или тангенс, сначала выписываем ограничения, а найденные серии проверяем по ним.

> [!example] Пример 3
> $(2\sin x - 1)\sqrt{-\cos x} = 0$. ОДЗ: $\cos x \le 0$.
>
> 1. $\sqrt{-\cos x} = 0 \iff \cos x = 0 \Rightarrow x = \frac{\pi}{2} + \pi k$ — все в ОДЗ.
> 2. $\sin x = \frac12$: $x = \frac{\pi}{6} + 2\pi k$ — там $\cos x = \frac{\sqrt3}{2} > 0$, **не подходит**; $x = \frac{5\pi}{6} + 2\pi k$ — там $\cos x = -\frac{\sqrt3}{2} \le 0$, подходит.
>
> Ответ: $x = \frac{\pi}{2} + \pi k$, $x = \frac{5\pi}{6} + 2\pi k$, $k \in \mathbb{Z}$.

### 4.5. Показательные и логарифмические уравнения

- Показательные: замена $t = a^{f(x)}$, **$t > 0$**.
- Логарифмические: сначала ОДЗ (аргумент больше нуля, основание больше нуля и не равно 1), потом переход $\log_a f(x) = b \iff f(x) = a^b$.

> [!example] Пример 4. Тригонометрия в показателе
> $9^{\sin x} + 9^{-\sin x} = \frac{10}{3}$.
>
> Пусть $t = 9^{\sin x} > 0$: $t + \frac1t = \frac{10}{3}$, $3t^2 - 10t + 3 = 0$, $t = 3$ или $t = \frac13$.
>
> $9^{\sin x} = 3 \Rightarrow \sin x = \frac12$; $\ 9^{\sin x} = \frac13 \Rightarrow \sin x = -\frac12$.
>
> Вместе: $\sin x = \pm\frac12$, то есть $x = \pm\frac{\pi}{6} + \pi k$, $k \in \mathbb{Z}$.

> [!example] Пример 5. Логарифмы
> $\log_3(x + 1) + \log_3(x + 3) = 1$. ОДЗ: $x > -1$.
>
> $\log_3\big((x + 1)(x + 3)\big) = 1 \Rightarrow x^2 + 4x + 3 = 3 \Rightarrow x(x + 4) = 0$.
>
> $x = 0$ подходит, $x = -4$ не входит в ОДЗ. Ответ: $0$.

## 5. Пункт б: отбор корней

Три способа. На экзамене достаточно одного, но он должен быть **виден в решении**.

### Способ 1. Единичная окружность

Отмечаем на окружности дугу, соответствующую отрезку, и точки серий; подписываем корни, которые попали на дугу.

![[trig-selection]] Отбор корней примера 1 на отрезке $\left[2\pi; \frac{7\pi}{2}\right]$: дуга — три четверти оборота от $2\pi$.

> [!example] Пример 1, пункт б
> Найдите корни, принадлежащие отрезку $\left[2\pi; \frac{7\pi}{2}\right]$.
>
> Отрезок начинается в точке $2\pi$ (угол $0$) и идёт против часовой стрелки на три четверти оборота до $\frac{7\pi}{2}$. На нём лежат $\frac{\pi}{6} + 2\pi = \frac{13\pi}{6}$, $\ \frac{\pi}{2} + 2\pi = \frac{5\pi}{2}$, $\ \frac{5\pi}{6} + 2\pi = \frac{17\pi}{6}$.
>
> Ответ б: $\frac{13\pi}{6}$; $\frac{5\pi}{2}$; $\frac{17\pi}{6}$.

### Способ 2. Двойное неравенство

Подставляем серию в границы отрезка и находим целые $k$.

> [!example] Корни $x = \operatorname{arctg} 2 + \pi k$ на отрезке $[0; 2\pi]$
> $0 \le \operatorname{arctg} 2 + \pi k \le 2\pi \iff -\frac{\operatorname{arctg} 2}{\pi} \le k \le 2 - \frac{\operatorname{arctg} 2}{\pi}$.
>
> Так как $0 < \operatorname{arctg} 2 < \frac{\pi}{2}$, подходят $k = 0$ и $k = 1$: корни $\operatorname{arctg} 2$ и $\pi + \operatorname{arctg} 2$.

### Способ 3. Перебор по числовой прямой

Выписываем значения серий подряд, пока не выйдем за границы. Удобно, когда отрезок короткий.

> [!remember] Проверка отбора
> Переведи границы и найденные корни в доли $\pi$ ($\frac{17\pi}{6} \approx 2{,}83\pi$, $\frac{7\pi}{2} = 3{,}5\pi$) и сравни. Ни один корень не должен выходить за отрезок, и ни одна серия не должна быть забыта.

## 6. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Выпиши ОДЗ, если есть дроби, корни, логарифмы или тангенс.
> 2. Приведи уравнение к одной функции (формулы двойного угла, основное тождество, приведения) или разложи на множители.
> 3. Сделай замену, реши алгебраическое уравнение, отбрось посторонние значения: $|\sin x| > 1$, $t \le 0$ для $t = a^x$.
> 4. Вернись к $x$, запиши серии с $k \in \mathbb{Z}$, сверь с ОДЗ — это ответ пункта а.
> 5. Отбери корни на отрезке одним из способов и **покажи** отбор — это пункт б.

## 7. Типичные ошибки

> [!mistake] Деление на $\sin x$ или $\cos x$
> Теряются корни, в которых этот множитель равен нулю. Выноси общий множитель за скобку.

> [!mistake] Корни вне ОДЗ
> В уравнении $(\operatorname{tg} x - 1)\sqrt{\cos x} = 0$ значения $\cos x = 0$ **не** корни: при них не определён тангенс.

> [!mistake] Период серии
> У $\cos x = a$ период $2\pi$, а у $\cos x = 0$ — короче: $\pi$. Перепутанный период теряет половину корней или добавляет лишние.

> [!mistake] $\sin x = 2$
> Такое уравнение корней не имеет: значения $t$ вне $[-1; 1]$ отбрасываются с пояснением.

## 8. Как проверить решение

- Подставь один корень из каждой серии в исходное уравнение.
- Проверь, что каждая серия удовлетворяет ОДЗ целиком, а не в одной точке.
- В пункте б убедись, что граничные точки отрезка проверены отдельно.

## 9. Потренируйся

1. а) Решите уравнение $2\sin^2 x + \cos x - 1 = 0$. б) Найдите корни на отрезке $\left[-\frac{3\pi}{2}; 0\right]$.
2. Решите уравнение $25^x - 6\cdot5^x + 5 = 0$.
3. Решите уравнение $(\operatorname{tg} x - 1)\sqrt{\cos x} = 0$.
4. Решите уравнение $\log_2(x^2 - 3x) = 2$.
5. а) Решите уравнение $\cos 2x = \sin x$. б) Найдите корни на отрезке $[0; \pi]$.

**Ответы.**
1. а) $2 - 2\cos^2 x + \cos x - 1 = 0 \Rightarrow 2\cos^2 x - \cos x - 1 = 0$, $\cos x = 1$ или $\cos x = -\frac12$: $x = 2\pi k$, $x = \pm\frac{2\pi}{3} + 2\pi k$. б) $-\frac{4\pi}{3}$; $-\frac{2\pi}{3}$; $0$.
2. $t = 5^x$: $t = 1$ или $t = 5$, $x = 0$ или $x = 1$.
3. Нужно $\cos x > 0$ (тангенс определён и корень имеет смысл), $\operatorname{tg} x = 1$: $x = \frac{\pi}{4} + 2\pi k$.
4. $x^2 - 3x = 4$: $x = 4$ или $x = -1$; оба в ОДЗ ($x^2 - 3x = 4 > 0$).
5. а) $1 - 2\sin^2 x = \sin x$, $\sin x = \frac12$ или $\sin x = -1$: $x = \frac{\pi}{6} + 2\pi k$, $x = \frac{5\pi}{6} + 2\pi k$, $x = -\frac{\pi}{2} + 2\pi k$. б) $\frac{\pi}{6}$; $\frac{5\pi}{6}$.
