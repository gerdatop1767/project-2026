# Вычисления и преобразования выражений

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — задание №7, часть 1, 1 балл. Проверяется: вычисления и преобразования выражений со степенями и логарифмами, преобразования дробно-рациональных выражений. На практике встречаются также корни и тригонометрия.
- **Старый сборник Ященко-2027** — задание №8.

Ответ здесь почти всегда «красивый» — целое число или конечная дробь. Если получилось что-то громоздкое, ищи ошибку в преобразованиях.

## 1. Степени

| Правило | Формула |
|---|---|
| Произведение | $a^m\cdot a^n = a^{m + n}$ |
| Частное | $a^m : a^n = a^{m - n}$ |
| Степень степени | $(a^m)^n = a^{mn}$ |
| Отрицательная степень | $a^{-n} = \dfrac{1}{a^n}$ |
| Дробная степень | $a^{\frac mn} = \sqrt[n]{a^m}$, $\ a > 0$ |

> [!example] Дробные степени
> $16^{0{,}75} = (2^4)^{\frac34} = 2^3 = 8$; $\quad 27^{\frac23} = (3^3)^{\frac23} = 9$.

## 2. Корни

- $\sqrt a\cdot\sqrt b = \sqrt{ab}$, $\ \dfrac{\sqrt a}{\sqrt b} = \sqrt{\dfrac ab}$ (для неотрицательных $a$, $b$): $\sqrt{18}\cdot\sqrt2 = \sqrt{36} = 6$.
- $\sqrt{a^2} = \lvert a\rvert$ — модуль, а не просто $a$.
- Разность квадратов: $(\sqrt a - \sqrt b)(\sqrt a + \sqrt b) = a - b$.

## 3. Логарифмы

$\log_a b = c \iff a^c = b$ ($a > 0$, $a \ne 1$, $b > 0$).

| Свойство | Формула |
|---|---|
| Основное тождество | $a^{\log_a b} = b$ |
| Сумма и разность | $\log_a b + \log_a c = \log_a(bc)$, $\ \log_a b - \log_a c = \log_a\frac bc$ |
| Степень | $\log_a b^k = k\log_a b$, $\ \log_{a^k} b = \frac1k\log_a b$ |
| Переход к новому основанию | $\log_a b = \dfrac{\log_c b}{\log_c a}$ |

> [!example] Логарифмы
> $\log_2 56 - \log_2 7 = \log_2 8 = 3$; $\quad \log_{\sqrt3} 9 = \log_{3^{1/2}} 3^2 = 4$; $\quad 3^{\log_3 7} = 7$.

## 4. Тригонометрия

| Формула | Запись |
|---|---|
| Основное тождество | $\sin^2\alpha + \cos^2\alpha = 1$ |
| Тангенс | $\operatorname{tg}\alpha = \dfrac{\sin\alpha}{\cos\alpha}$, $\ 1 + \operatorname{tg}^2\alpha = \dfrac1{\cos^2\alpha}$ |
| Двойной угол | $\sin2\alpha = 2\sin\alpha\cos\alpha$, $\ \cos2\alpha = \cos^2\alpha - \sin^2\alpha$ |
| Формулы приведения | $\sin(\pi - \alpha) = \sin\alpha$, $\ \cos(\pi - \alpha) = -\cos\alpha$, $\ \sin(\frac\pi2 - \alpha) = \cos\alpha$ |

> [!remember] Знак — по четверти
> Из $\sin^2\alpha = 1 - \cos^2\alpha$ корень даёт **два** знака. Выбирай по четверти, в которой лежит $\alpha$: в I все функции положительны, во II — только синус, в III — тангенс, в IV — косинус.

> [!example] Синус по косинусу
> $\cos\alpha = 0{,}6$, $\alpha$ в IV четверти. Тогда $\sin\alpha = -\sqrt{1 - 0{,}36} = -0{,}8$, и $5\sin\alpha = -4$.

## 5. Дробно-рациональные выражения

1. Разложи числители и знаменатели на множители: вынеси общий множитель, применяй формулы сокращённого умножения.
2. Сократи общие множители.
3. Только потом подставляй значение переменной.

## 6. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Сначала упрости, потом подставляй числа: так меньше вычислений.
> 2. Приводи степени и логарифмы к **одному основанию**: $4 = 2^2$, $0{,}25 = 2^{-2}$, $\sqrt3 = 3^{1/2}$.
> 3. Для тригонометрии — основное тождество и знак по четверти.
> 4. Проверь, что ответ «круглый». Если нет — перепроверь.

## 7. Типичные ошибки

> [!mistake] Логарифм суммы
> $\log_a(b + c) \ne \log_a b + \log_a c$. Сумма логарифмов — это логарифм **произведения**.

> [!mistake] Степень суммы
> $(a + b)^2 \ne a^2 + b^2$, и $\sqrt{a + b} \ne \sqrt a + \sqrt b$.

## 8. Потренируйся

1. $\log_5 0{,}2 + \log_3 81$.
2. $(\sqrt{13} - \sqrt3)(\sqrt{13} + \sqrt3)$.
3. $\cos\alpha = -0{,}6$, $\alpha \in \left(\frac\pi2; \pi\right)$. Найди $10\sin\alpha$.

**Ответы.**
1. $-1 + 4 = 3$.
2. $13 - 3 = 10$.
3. Во II четверти синус положителен: $\sin\alpha = 0{,}8$, ответ 8.
