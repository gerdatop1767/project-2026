# Векторы

Где это на экзамене:

- **ЕГЭ-2027 и ЕГЭ-2026** — задание №2, часть 1, 1 балл. Проверяется: вектор, координаты вектора, сумма векторов, произведение вектора на число, скалярное произведение, угол между векторами.
- **Старый сборник Ященко-2027** — тоже №2.

## 1. Координаты вектора

Вектор $\vec{AB}$ с началом $A(x_1; y_1)$ и концом $B(x_2; y_2)$ имеет координаты «конец минус начало»:

$$\vec{AB} = (x_2 - x_1;\ y_2 - y_1)$$

Длина вектора $\vec a(x; y)$:

$$\lvert\vec a\rvert = \sqrt{x^2 + y^2}$$

> [!remember] Конец минус начало
> Перепутать порядок — значит получить противоположный вектор. Длина при этом та же, но координаты и скалярное произведение будут неверными.

## 2. Действия с векторами

| Действие | В координатах | Геометрически |
|---|---|---|
| Сумма $\vec a + \vec b$ | $(x_1 + x_2;\ y_1 + y_2)$ | правило треугольника или параллелограмма |
| Разность $\vec a - \vec b$ | $(x_1 - x_2;\ y_1 - y_2)$ | вектор из конца $\vec b$ в конец $\vec a$ |
| Умножение на число $k\vec a$ | $(kx;\ ky)$ | растяжение в $\lvert k\rvert$ раз, при $k < 0$ — разворот |

![[vec-parallelogram]] $\vec a = (3; 1)$, $\vec b = (1; 2)$. Их сумма — диагональ параллелограмма: $(4; 3)$, её длина $\sqrt{16 + 9} = 5$.

> [!example] Длина линейной комбинации
> $\vec a(2; 2)$, $\vec b(2; -2)$. Найдите $\lvert 7\vec a - \vec b\rvert$.
> $7\vec a - \vec b = (14 - 2;\ 14 + 2) = (12; 16)$, длина $\sqrt{144 + 256} = 20$.

## 3. Скалярное произведение

$$\vec a\cdot\vec b = x_1x_2 + y_1y_2 = \lvert\vec a\rvert\,\lvert\vec b\rvert\cos\varphi$$

Отсюда угол между векторами:

$$\cos\varphi = \frac{x_1x_2 + y_1y_2}{\lvert\vec a\rvert\,\lvert\vec b\rvert}$$

| Знак скалярного произведения | Угол $\varphi$ |
|---|---|
| больше 0 | острый |
| равно 0 | прямой: векторы перпендикулярны |
| меньше 0 | тупой |

- $\vec a\cdot\vec a = \lvert\vec a\rvert^2$ — квадрат длины.
- $(\vec a + \vec b)^2 = \lvert\vec a\rvert^2 + 2\,\vec a\cdot\vec b + \lvert\vec b\rvert^2$ — так считают длину суммы, когда даны длины и угол, а координат нет.

> [!example] Перпендикулярность и угол
> $\vec a(3; 4)$, $\vec b(4; -3)$: $3\cdot4 + 4\cdot(-3) = 0$ — векторы перпендикулярны.
> $\vec a(1; 0)$, $\vec b(1; 1)$: $\cos\varphi = \frac{1}{1\cdot\sqrt2}$, $\varphi = 45^\circ$.

## 4. Векторы по рисунку на клетчатой сетке

Часто векторы нарисованы на клетках. Тогда:

1. Найди координаты каждого вектора: сколько клеток вправо (плюс) или влево (минус), сколько вверх (плюс) или вниз (минус) от начала до конца.
2. Дальше работай только с координатами — по формулам выше.

## 5. Как решать на ЕГЭ

> [!exam] Алгоритм
> 1. Перейди к координатам: из условия, по точкам («конец минус начало») или по клеткам.
> 2. Выполни действия покоординатно: сумма, разность, умножение на число.
> 3. Для длины — корень из суммы квадратов, для угла и перпендикулярности — скалярное произведение.
> 4. Если в ответе косинус угла, проверь, что он лежит от $-1$ до $1$.

## 6. Типичные ошибки

> [!mistake] Длина суммы — не сумма длин
> $\lvert\vec a + \vec b\rvert \ne \lvert\vec a\rvert + \lvert\vec b\rvert$ (равенство только для сонаправленных векторов). Сначала сложи векторы, потом бери длину.

> [!mistake] Число умножили только на одну координату
> $3\vec a$ для $\vec a(2; -1)$ — это $(6; -3)$, обе координаты умножаются.

## 7. Потренируйся

1. Найди длину вектора $\vec a(-6; 8)$.
2. Найди скалярное произведение векторов $\vec a(1; 2)$ и $\vec b(3; -4)$.
3. При каком $x$ векторы $\vec a(2; 3)$ и $\vec b(x; -4)$ перпендикулярны?

**Ответы.**
1. $\sqrt{36 + 64} = 10$.
2. $3 - 8 = -5$.
3. $2x - 12 = 0$, $x = 6$.
