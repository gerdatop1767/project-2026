# Типичные ошибки по математике

Ошибки, на которых теряют баллы при правильном понимании темы. Рядом — как правильно.

## Первая часть

| Ошибка | Как правильно |
|---|---|
| в ответ записан $x$ вместо значения функции (№12) | читай вопрос: «точка максимума» — $x$, «наибольшее значение» — $y$ |
| $\frac13$ забыта в объёме пирамиды или конуса (№3) | $V = \frac13 Sh$ |
| при подобии тел площадь умножена на $k$ (№3) | площадь — на $k^2$, объём — на $k^3$ |
| сложили вероятности «и» (№4, №5) | для «и» независимые вероятности перемножают |
| «хотя бы один» считали перебором | $1 - P(\text{ни одного})$ |
| в №8 по графику $f$ искали знаки $f'$ как по графику $f'$ | сначала посмотри, что изображено: функция или производная |
| посторонний корень иррационального уравнения (№6) | проверка подстановкой или условие $g \ge 0$ |
| ответ в неверных единицах (№9, №10) | минуты ↔ часы, метры ↔ километры — в тех, что спрашивают |
| записана обыкновенная дробь | в бланке — целое число или конечная десятичная дробь |

## Вторая часть

| Ошибка | Как правильно |
|---|---|
| деление уравнения на $\sin x$ (№13) | вынести множитель за скобку, иначе теряются корни |
| отбор корней без обоснования | окружность, двойное неравенство или перебор — показать в решении |
| выколота нужная точка или закрашена лишняя (№15) | проверить каждую граничную точку подстановкой |
| в №16 проценты начислены после платежа | сначала начисление, потом платёж |
| угол «на рисунке» без доказательства (№14, №17) | обосновать построение теоремой: ТТП, признак перпендикулярности |
| случай $a = 0$ при $a$ перед $x^2$ (№18) | рассмотреть отдельно: уравнение становится линейным |
| оценка без примера (№19 в) | нужны и оценка, и пример, на котором она достигается |

> [!mistake] Перенос в бланк
> Самая обидная потеря — верный ответ в черновике и неверный в бланке. После переноса сверь каждый номер.

> [!tip] Совет Зубра
> Заведи личный список «моих» ошибок из этой таблицы и перечитывай его перед каждым пробником.
