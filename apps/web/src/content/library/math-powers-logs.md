# Степени, корни и логарифмы

Свойства нужны в **№6** и **№7** (уравнения и вычисления) и в **№13**, **№15** (развёрнутые решения).

## Степени

| Свойство | Формула |
|---|---|
| произведение степеней | $a^m\cdot a^n = a^{m+n}$ |
| частное | $\frac{a^m}{a^n} = a^{m-n}$ |
| степень степени | $(a^m)^n = a^{mn}$ |
| степень произведения | $(ab)^n = a^n b^n$ |
| нулевая и отрицательная | $a^0 = 1$, $\ a^{-n} = \frac{1}{a^n}$ |
| дробная | $a^{\frac mn} = \sqrt[n]{a^m}$, $\ a > 0$ |

## Корни

- $\sqrt{ab} = \sqrt a\cdot\sqrt b$ при $a, b \ge 0$; $\ \sqrt{\frac ab} = \frac{\sqrt a}{\sqrt b}$ при $a \ge 0$, $b > 0$.
- $\sqrt{a^2} = \lvert a\rvert$ — модуль обязателен.
- $(\sqrt a)^2 = a$ при $a \ge 0$.

## Логарифмы

$\log_a b = c \iff a^c = b$, где $a > 0$, $a \ne 1$, $b > 0$.

| Свойство | Формула |
|---|---|
| основное тождество | $a^{\log_a b} = b$ |
| логарифм произведения | $\log_a(bc) = \log_a b + \log_a c$ |
| логарифм частного | $\log_a\frac bc = \log_a b - \log_a c$ |
| степень аргумента | $\log_a b^n = n\log_a b$ |
| степень основания | $\log_{a^k} b = \frac1k\log_a b$ |
| переход к новому основанию | $\log_a b = \frac{\log_c b}{\log_c a}$ |
| частные случаи | $\log_a 1 = 0$, $\ \log_a a = 1$, $\ \log_a b = \frac{1}{\log_b a}$ |

> [!example] Вычисление
> $\log_2 56 - \log_2 7 = \log_2 8 = 3$; $\ 5^{\log_5 9} = 9$; $\ \log_{27} 9 = \frac{\log_3 9}{\log_3 27} = \frac23$.

## ОДЗ — что проверить

| Выражение | Условие |
|---|---|
| $\sqrt{f(x)}$ | $f(x) \ge 0$ |
| $\frac{1}{g(x)}$ | $g(x) \ne 0$ |
| $\log_{h(x)} f(x)$ | $f(x) > 0$, $h(x) > 0$, $h(x) \ne 1$ |
| $\operatorname{tg} x$ | $\cos x \ne 0$ |

> [!mistake] Логарифм суммы
> $\log_a(b + c) \ne \log_a b + \log_a c$. Свойство работает только для произведения.

> [!mistake] Потеря модуля
> $\log_2 x^2 = 2\log_2\lvert x\rvert$, а $2\log_2 x$ — только при $x > 0$. Без модуля теряются отрицательные корни.

> [!tip] Совет Зубра
> Перед вычислением логарифма попробуй записать аргумент как степень основания: $81 = 3^4$, $0{,}125 = 2^{-3}$.
