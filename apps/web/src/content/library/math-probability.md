# Вероятность и статистика: формулы и схемы

Справочник к **№4** и **№5**.

## Основные формулы

| Ситуация | Формула |
|---|---|
| классическая вероятность | $P(A) = \frac{m}{n}$ — благоприятные исходы / все равновозможные |
| противоположное событие | $P(\overline A) = 1 - P(A)$ |
| несовместные события («или») | $P(A + B) = P(A) + P(B)$ |
| любые события «или» | $P(A \cup B) = P(A) + P(B) - P(AB)$ |
| независимые события («и») | $P(AB) = P(A)\cdot P(B)$ |
| условная вероятность | $P(A\mid B) = \frac{P(AB)}{P(B)}$ |
| полная вероятность | $P(A) = P(H_1)P(A\mid H_1) + P(H_2)P(A\mid H_2) + \dots$ |
| схема Бернулли | $P_n(k) = C_n^k p^k (1 - p)^{n - k}$ |
| сочетания | $C_n^k = \frac{n!}{k!\,(n - k)!}$ |

## Как выбрать формулу

| Слова в условии | Действие |
|---|---|
| «хотя бы один» | $1 - P(\text{ни одного})$ |
| «и… и…», «оба», «все» | умножение (если независимы) |
| «или», «один из» | сложение несовместных вариантов |
| «из двух заводов», «из двух партий» | полная вероятность, дерево |
| «ровно $k$ раз из $n$» | схема Бернулли |

> [!example] Хотя бы одно попадание
> Стрелок попадает с вероятностью 0,8. Вероятность хотя бы одного попадания из трёх выстрелов: $1 - 0{,}2^3 = 1 - 0{,}008 = 0{,}992$.

> [!example] Полная вероятность
> Завод 1 выпускает 60 % изделий, брак 2 %; завод 2 — 40 %, брак 3 %. $P(\text{брак}) = 0{,}6\cdot0{,}02 + 0{,}4\cdot0{,}03 = 0{,}012 + 0{,}012 = 0{,}024$.

## Случайная величина

- Математическое ожидание: $E(X) = x_1p_1 + x_2p_2 + \dots + x_np_n$.
- Дисперсия: $D(X) = E(X^2) - \big(E(X)\big)^2$, стандартное отклонение $\sigma = \sqrt{D(X)}$.
- Для числа успехов в схеме Бернулли: $E = np$, $D = np(1 - p)$.

## Статистика

- Среднее арифметическое — сумма, делённая на количество.
- Медиана — середина упорядоченного ряда (при чётном числе значений — среднее двух средних).
- Размах — разность наибольшего и наименьшего значений.

> [!mistake] Сложение вместо умножения
> «Оба автомата исправны» — это «и», вероятности перемножают. Складывают только для «или» и только несовместные события.

> [!mistake] Ответ больше 1
> Вероятность всегда от 0 до 1. Если получилось больше — где-то сложены совместные события.
