# Сочинение: план, связки и формулировки

К **заданию 27**. Формулировки — заготовки, а не готовый текст: каждую нужно наполнить содержанием исходного текста. Критерии — по демоверсии ФИПИ 2027 года.

## План и критерии

| Часть | Критерий | Объём (ориентир) |
|---|---|---|
| вступление: подводка к проблеме из задания | — | 2–3 предложения |
| позиция автора | К1 — 1 балл | 1–2 предложения |
| пример 1 + пояснение | К2 | 3–4 предложения |
| пример 2 + пояснение | К2 | 3–4 предложения |
| смысловая связь + её пояснение | К2 — до 3 баллов вместе с примерами | 2 предложения |
| своё отношение + обоснование + пример-аргумент | К3 — 2 балла | 4–5 предложений |
| вывод | — | 1–2 предложения |

Минимум — **150 слов**; при 149 и меньше все критерии оцениваются нулём.

## Формулировки для каждой части

**Позиция автора (К1):**
- «Автор убеждён, что…»
- «По мысли писателя, …»
- «Позиция автора ясна: …»

**Пример-иллюстрация (К2):**
- «Чтобы раскрыть эту мысль, автор рассказывает о… (предложения 5–7).»
- «Важен эпизод, в котором… Он показывает, что…»
- «Обратим внимание на слова героя: «…». Ими автор подчёркивает…»

**Смысловая связь (К2):**

| Тип связи | Формулировка |
|---|---|
| противопоставление | «Примеры противопоставлены: в первом… , во втором… Это помогает понять, что…» |
| причина и следствие | «Второй пример — следствие первого: именно потому что…, …» |
| дополнение | «Второй пример дополняет первый: автор показывает не только…, но и…» |
| общее и частное | «Первый пример выражает общую мысль, второй конкретизирует её…» |

**Своё отношение (К3):**
- «Я согласен с автором, потому что…» — дальше обязательно обоснование.
- «Подтверждение этой мысли я нахожу в романе… Герой…»
- «Из истории известен пример…»

> [!mistake] Формальное согласие
> «Я полностью согласен с автором» без обоснования и примера оценивается как формальное — 0 баллов по К3.

> [!mistake] Пример из недопустимого источника
> Не засчитываются примеры из комиксов, аниме, манги, фанфиков, графических романов, компьютерных игр. Опирайся на книги, историю и реальный жизненный опыт.

## Связки между частями

| Переход | Связка |
|---|---|
| к первому примеру | «Обратимся к тексту», «В первом эпизоде…» |
| ко второму | «Кроме того», «Другой пример…», «Иначе…» |
| к своему мнению | «Позиция автора мне близка», «Не могу не согласиться…» |
| к выводу | «Таким образом», «Итак», «Подводя итог…» |

> [!tip] Совет Зубра
> Связки делают текст связным, но не заменяют мысль. Одна связка — одна новая мысль; не начинай подряд три предложения с «Таким образом».
