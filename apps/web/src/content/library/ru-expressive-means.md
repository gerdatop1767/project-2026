# Средства выразительности: таблица

К **заданиям 3 и 22**. В №22 фрагменты обычно из классики, нужно сопоставить пять фрагментов с девятью терминами.

## Тропы (перенос значения)

| Термин | Что это | Пример |
|---|---|---|
| эпитет | образное определение | *весёлый свет, золотая осень* |
| метафора | скрытое сравнение, перенос по сходству | *море огней, золото листвы* |
| олицетворение | неживое наделено свойствами живого | *лес уснул, ветер шепчет* |
| сравнение | сопоставление с «как, словно, будто» или творительным падежом | *лёгкий, как пух; летит стрелой* |
| метонимия | замена по смежности | *фарфор и бронза на столе; прочитал Пушкина* |
| синекдоха | часть вместо целого, ед. ч. вместо мн. ч. | *швед, русский колет; пять ртов* |
| гипербола | преувеличение | *сто лет не виделись* |
| литота | преуменьшение | *мужичок с ноготок* |
| перифраза | описательное название | *царь зверей* |
| ирония | насмешка через противоположный смысл | *Отколе, умная, бредёшь ты, голова?* (И. А. Крылов, «Лисица и Осёл» — об осле) |

## Фигуры речи (синтаксис)

| Термин | Что это | Пример |
|---|---|---|
| анафора | повтор в начале строк или фраз | *Я звал тебя, я ждал тебя* |
| эпифора | повтор в конце фраз | *На улице всё тихо. В доме всё тихо. В душе всё тихо.* |
| антитеза | противопоставление | *Они сошлись. Волна и камень, стихи и проза, лёд и пламень* |
| градация | нарастание | *просил, умолял, молил* |
| риторический вопрос | вопрос без ожидания ответа | *К чему бесплодно спорить с веком?* |
| риторическое восклицание | эмоциональное восклицание | *Ах! Долго я забыть не мог…* |
| риторическое обращение | обращение к неодушевлённому или отсутствующему | *Москва! как много в этом звуке…* |
| многосоюзие | повтор союзов | *И тесноту, и блеск, и радость* |
| бессоюзие | пропуск союзов | *Швед, русский — колет, рубит, режет* |
| инверсия | необычный порядок слов | *Белеет парус одинокий* |
| парцелляция | дробление на короткие предложения | *Он ушёл. Навсегда.* |

## Лексические средства

Синонимы и контекстные синонимы, антонимы и контекстные антонимы, фразеологизмы, разговорная, книжная, устаревшая лексика, диалектизмы, термины, лексический повтор.

## Как отличать похожие

| Пара | Ключ |
|---|---|
| эпитет / метафора | эпитет — прилагательное при существительном; метафора — перенос любой частью речи |
| метафора / сравнение | в сравнении есть «как» или творительный падеж |
| метафора / олицетворение | если неживому приписано действие живого — олицетворение |
| метонимия / синекдоха | смежность (материал, автор, место) / часть и целое, число |

> [!mistake] Любое определение — эпитет
> «Двойные фонари» — прямое значение, не эпитет. Эпитет — образное определение.

> [!tip] Совет Зубра
> Сначала распредели синтаксические средства (вопросы, восклицания, повторы, союзы) — их видно сразу. Тропы — в конце, когда выбор меньше.
