# Уравнения и неравенства: шпаргалка по типам

Для **№6**, **№13**, **№15** и **№18**. Главное в каждом типе — равносильный переход и ОДЗ.

## Уравнения

| Тип | Как решать | ОДЗ и проверка |
|---|---|---|
| квадратное $ax^2 + bx + c = 0$ | $D = b^2 - 4ac$, $x = \frac{-b \pm \sqrt D}{2a}$; теорема Виета $x_1 + x_2 = -\frac ba$, $x_1x_2 = \frac ca$ | при $a$ с параметром отдельно случай $a = 0$ |
| дробное $\frac{f}{g} = 0$ | $f = 0$ и $g \ne 0$ | корни знаменателя исключить |
| иррациональное $\sqrt f = g$ | $f = g^2$ и $g \ge 0$ | проверка подстановкой |
| с модулем $\lvert f\rvert = a$ | $f = \pm a$ при $a \ge 0$ | при $a < 0$ корней нет |
| $\lvert f\rvert = g$ | $f = \pm g$ и $g \ge 0$ | — |
| показательное $a^{f} = a^{g}$ | $f = g$ | замена $t = a^x$, $t > 0$ |
| логарифмическое $\log_a f = \log_a g$ | $f = g$ | $f > 0$ (или $g > 0$), $a > 0$, $a \ne 1$ |
| тригонометрическое | к одной функции, замена, разложение на множители | ОДЗ тангенса, корней, дробей; отбор корней |

## Неравенства

| Тип | Равносильный переход |
|---|---|
| рациональное | всё в одну сторону, дробь, метод интервалов |
| $\sqrt f < g$ | $f \ge 0$, $g > 0$, $f < g^2$ |
| $\sqrt f > g$ | ($g < 0$ и $f \ge 0$) или ($g \ge 0$ и $f > g^2$) |
| $\lvert f\rvert < g$ | $-g < f < g$ |
| $\lvert f\rvert > g$ | $f > g$ или $f < -g$ |
| $a^f > a^g$ | $f > g$ при $a > 1$; $f < g$ при $0 < a < 1$ |
| $\log_a f > \log_a g$ | $f > g > 0$ при $a > 1$; $0 < f < g$ при $0 < a < 1$ |

## Метод рационализации

На ОДЗ знак сложного множителя совпадает со знаком простого:

| Множитель | Заменяем на |
|---|---|
| $\log_a f - \log_a g$ | $(a - 1)(f - g)$ |
| $a^f - a^g$ | $(a - 1)(f - g)$ |
| $\lvert f\rvert - \lvert g\rvert$ | $(f - g)(f + g)$ |
| $\sqrt f - \sqrt g$ | $f - g$ |

> [!mistake] Возведение в квадрат без условия
> $\sqrt{x + 2} = x$ даёт после возведения $x = 2$ и $x = -1$. Корень $-1$ посторонний: правая часть отрицательна. Условие $g \ge 0$ пишется сразу.

> [!mistake] Умножение неравенства на выражение с $x$
> Знак выражения неизвестен — неравенство может развернуться. Переноси всё в одну сторону.

> [!tip] Совет Зубра
> Пиши ОДЗ первой строкой решения, а не в конце. Тогда отбор корней не забудется.
