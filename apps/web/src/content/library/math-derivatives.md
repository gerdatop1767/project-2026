# Таблица производных и правила дифференцирования

Производная нужна в заданиях **№8** (геометрический смысл, графики $f$ и $f'$) и **№12** (наибольшее и наименьшее значение, точки экстремума).

## Таблица производных

| Функция $f(x)$ | Производная $f'(x)$ |
|---|---|
| $C$ (константа) | $0$ |
| $x$ | $1$ |
| $x^n$ | $n x^{n-1}$ |
| $\sqrt x$ | $\frac{1}{2\sqrt x}$ |
| $\frac1x$ | $-\frac{1}{x^2}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x\ln a$ |
| $\ln x$ | $\frac1x$ |
| $\log_a x$ | $\frac{1}{x\ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\operatorname{tg} x$ | $\frac{1}{\cos^2 x}$ |
| $\operatorname{ctg} x$ | $-\frac{1}{\sin^2 x}$ |

## Правила дифференцирования

| Правило | Формула |
|---|---|
| сумма | $(u + v)' = u' + v'$ |
| множитель-константа | $(Cu)' = Cu'$ |
| произведение | $(uv)' = u'v + uv'$ |
| частное | $\left(\frac uv\right)' = \frac{u'v - uv'}{v^2}$ |
| сложная функция | $\big(f(g(x))\big)' = f'(g(x))\cdot g'(x)$ |

> [!example] Сложная функция
> $\big((2x + 1)^5\big)' = 5(2x + 1)^4\cdot 2 = 10(2x + 1)^4$; $\ (e^{3x})' = 3e^{3x}$; $\ \big(\ln(x^2 + 1)\big)' = \frac{2x}{x^2 + 1}$.

## Геометрический и физический смысл

![[deriv-tangent]] Касательная к графику $y = \frac{x^2}{4}$ в точке $x_0 = 2$: её угловой коэффициент равен $f'(2) = 1$.

- $f'(x_0)$ — угловой коэффициент касательной в точке $x_0$: $f'(x_0) = k = \operatorname{tg}\alpha$.
- Уравнение касательной: $y = f(x_0) + f'(x_0)(x - x_0)$.
- Если $s(t)$ — путь, то $v(t) = s'(t)$ — скорость, $a(t) = v'(t)$ — ускорение.

## Производная и поведение функции

| Знак $f'$ на промежутке | Что делает $f$ |
|---|---|
| $f' > 0$ | возрастает |
| $f' < 0$ | убывает |
| $f'$ меняет знак с «+» на «−» | точка максимума |
| $f'$ меняет знак с «−» на «+» | точка минимума |

![[deriv-signs]] По графику производной: нули — точки, где может быть экстремум; знак — возрастание или убывание.

> [!remember] Наибольшее значение на отрезке
> Найди критические точки внутри отрезка, вычисли $f$ в них и **на концах отрезка**, выбери наибольшее. Если на отрезке одна точка максимума и других критических точек нет, наибольшее значение — в ней.

> [!mistake] Точка и значение
> «Найдите точку максимума» — ответ $x$; «найдите наибольшее значение» — ответ $y = f(x)$. Перепутать — потерять балл при верном решении.

> [!tip] Совет Зубра
> По графику **производной** ищи знаки, по графику **функции** — наклон касательной. Сначала посмотри на подпись оси: где $f$, а где $f'$.
