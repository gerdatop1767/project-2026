# Графики функций и их преобразования

Для **№8**, **№11** и **№18**: узнать функцию по графику, восстановить формулу, построить график для задачи с параметром.

## Элементарные функции

| Функция | Вид графика | Ключевые точки |
|---|---|---|
| $y = kx + b$ | прямая | пересечение с $Oy$ в $(0; b)$, наклон $k = \frac{\Delta y}{\Delta x}$ |
| $y = ax^2 + bx + c$ | парабола | вершина $x_0 = -\frac{b}{2a}$; $a > 0$ — ветви вверх |
| $y = \frac kx$ | гипербола | асимптоты — оси; $k > 0$ — I и III четверти |
| $y = \sqrt x$ | ветвь параболы | начало в $(0; 0)$, проходит $(1; 1)$, $(4; 2)$ |
| $y = a^x$ | показательная | проходит $(0; 1)$; асимптота $y = 0$ |
| $y = \log_a x$ | логарифмическая | проходит $(1; 0)$; асимптота $x = 0$ |
| $y = \sin x$, $y = \cos x$ | синусоида | период $2\pi$, значения от $-1$ до $1$ |
| $y = \lvert x\rvert$ | «галочка» | вершина в $(0; 0)$ |

## Преобразования графиков

| Формула | Что происходит с графиком $y = f(x)$ |
|---|---|
| $y = f(x) + b$ | сдвиг вверх на $b$ (вниз при $b < 0$) |
| $y = f(x - a)$ | сдвиг **вправо** на $a$ |
| $y = kf(x)$ | растяжение от оси $Ox$ в $k$ раз |
| $y = f(kx)$ | сжатие к оси $Oy$ в $k$ раз |
| $y = -f(x)$ | отражение относительно $Ox$ |
| $y = f(-x)$ | отражение относительно $Oy$ |
| $y = \lvert f(x)\rvert$ | части ниже $Ox$ отражаются вверх |
| $y = f(\lvert x\rvert)$ | правая половина копируется в левую |

> [!example] Восстановить формулу
> Парабола с вершиной $(2; -1)$ проходит через $(0; 3)$: $y = a(x - 2)^2 - 1$, $3 = 4a - 1$, $a = 1$.

> [!mistake] Сдвиг не в ту сторону
> $y = (x - 3)^2$ сдвинута **вправо** на 3: вершина в $x = 3$, где скобка обращается в ноль.

> [!tip] Совет Зубра
> Ищи на рисунке точки в узлах сетки — их координаты целые, по ним формула восстанавливается точно.
