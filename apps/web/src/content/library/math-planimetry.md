# Планиметрия: формулы и теоремы

Справочник к **№1** (вычисления) и **№17** (доказательство и вычисление).

## Треугольник

| Что | Формула |
|---|---|
| сумма углов | $180°$ |
| площадь | $S = \frac12 a h_a = \frac12 ab\sin C = \sqrt{p(p-a)(p-b)(p-c)}$ |
| через радиусы | $S = pr = \frac{abc}{4R}$ ($p$ — полупериметр) |
| теорема косинусов | $c^2 = a^2 + b^2 - 2ab\cos C$ |
| теорема синусов | $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ |
| медиана | $m_c = \frac12\sqrt{2a^2 + 2b^2 - c^2}$; медианы делятся точкой пересечения $2 : 1$ от вершины |
| биссектриса | делит сторону в отношении прилежащих сторон: $\frac{BL}{LC} = \frac{AB}{AC}$ |
| средняя линия | параллельна стороне и равна её половине |

## Прямоугольный треугольник

- $a^2 + b^2 = c^2$ (теорема Пифагора).
- $\sin A = \frac ac$, $\cos A = \frac bc$, $\operatorname{tg} A = \frac ab$.
- Медиана к гипотенузе равна её половине; центр описанной окружности — середина гипотенузы, $R = \frac c2$.
- Радиус вписанной окружности: $r = \frac{a + b - c}{2}$.
- Высота к гипотенузе: $h = \frac{ab}{c}$.

## Четырёхугольники

| Фигура | Площадь | Важные свойства |
|---|---|---|
| параллелограмм | $ah$, $ab\sin\alpha$ | диагонали делятся пополам |
| ромб | $\frac12 d_1 d_2$ | диагонали перпендикулярны и делят углы пополам |
| прямоугольник | $ab$ | диагонали равны |
| трапеция | $\frac{a + b}{2}h$ | средняя линия $\frac{a + b}{2}$ |
| любой | $\frac12 d_1 d_2\sin\varphi$ | — |

## Окружность

- Длина $2\pi R$, площадь круга $\pi R^2$, длина дуги $\frac{\pi R\alpha}{180°}$, площадь сектора $\frac{\pi R^2\alpha}{360°}$.
- Вписанный угол равен половине центрального, опирающегося на ту же дугу; угол на диаметр — прямой.
- Касательная перпендикулярна радиусу; отрезки касательных из одной точки равны.
- Касательная и секущая: $PT^2 = PA\cdot PB$; пересекающиеся хорды: $AP\cdot PB = CP\cdot PD$.
- Вписанный четырёхугольник: суммы противоположных углов по $180°$. Описанный: $a + c = b + d$.

## Подобие

Коэффициент $k$: линейные размеры относятся как $k$, площади — как $k^2$. Признаки: два угла; две стороны и угол между ними; три стороны.

> [!remember] Где искать подобие
> Параллельные прямые, общий угол, вписанные углы на одну дугу, высоты треугольника (треугольник из оснований высот подобен исходному с $k = \lvert\cos C\rvert$).

> [!mistake] Теорема синусов без $2R$
> $\frac{a}{\sin A} = 2R$ — удобный путь к радиусу описанной окружности. Его часто забывают и ищут $R$ длинным путём.
