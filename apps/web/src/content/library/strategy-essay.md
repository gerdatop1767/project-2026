# Как писать сочинение по русскому языку

Порядок работы, распределение времени и проверка по критериям К1–К10 демоверсии ФИПИ 2027 года.

## Порядок работы

| Шаг | Время (ориентир) | Что делать |
|---|---|---|
| 1. Чтение с вопросом | 10 мин | прочитать текст, держа в голове вопрос из задания; отметить номера предложений |
| 2. Позиция автора | 5 мин | сформулировать ответ автора на вопрос одним-двумя предложениями |
| 3. Два примера | 10 мин | выбрать два эпизода, важных для позиции, и написать, что каждый показывает |
| 4. Связь | 5 мин | определить связь примеров и объяснить её |
| 5. Свой аргумент | 5–10 мин | выбрать пример из литературы, истории или жизни, который подтверждает или опровергает позицию |
| 6. Черновик и чистовик | 50–60 мин | написать, переписать, исправив повторы |
| 7. Проверка | 10 мин | подсчитать слова, проверить грамотность |

## Проверка по критериям

| Критерий | Вопрос к себе |
|---|---|
| К1 | Позиция автора — это ответ на вопрос задания? Не мнение героя? |
| К2 | Два примера из текста? У каждого пояснение? Связь названа и объяснена? |
| К3 | Моё отношение сформулировано и обосновано? Есть пример-аргумент из допустимого источника? |
| К4 | Нет фактических ошибок в именах, датах, названиях? |
| К5 | Мысли идут по порядку, абзацы связаны? |
| К6 | Нет некорректных высказываний? |
| К7–К10 | Орфография, пунктуация, грамматика, речевые повторы проверены? |

> [!remember] Объём
> Не менее 150 слов. При 149 и меньше работа оценивается нулём по всем критериям. Считаются все слова, включая предлоги и союзы.

> [!mistake] Пример-аргумент повторяет текст
> Аргумент не должен повторять суждения автора. Нужен **свой** пример из другой книги, истории или жизни.

> [!mistake] Слишком длинное сочинение
> Объём свыше 150 слов не даёт баллов сам по себе, а ошибок в длинном тексте больше. Пиши ровно столько, сколько нужно для всех частей плана.

> [!tip] Совет Зубра
> Держи в памяти 3–4 произведения, которые хорошо знаешь, и думай заранее, к каким проблемам они подходят. На экзамене не придётся вспоминать сюжет с нуля.
