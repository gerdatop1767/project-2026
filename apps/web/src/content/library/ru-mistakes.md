# Типичные ошибки по русскому языку

Ошибки, на которых теряют баллы чаще всего, — с правильным вариантом.

## Первая часть

| № | Ошибка | Как правильно |
|---|---|---|
| 1 | слово не того разряда («все» вместо указательного) | сверить разряд с формулировкой задания |
| 2 | значение выбрано без подстановки в предложение | подставить толкование вместо слова |
| 4 | ударение по привычке: звОнит, свеклА | только по «Орфоэпическому списку»: звонИт, свЁкла |
| 5 | синоним вместо паронима | замена из той же паронимической группы |
| 6 | убрано не то слово при плеоназме | «очень оптимальный» — лишнее «очень» |
| 7 | «пара туфлей», «более лучше» | пара туфель, лучше |
| 9 | чередующийся корень проверен ударением | условие выбора буквы по таблице чередований |
| 12 | спряжение определено по форме, а не по инфинитиву | выглянешь — выглянуть, I спр. |
| 13 | «но» принято за противопоставление | неширокий, но глубокий — слитно |
| 14 | «по-зимнему парку» | по зимнему парку (есть существительное) |
| 15 | одна Н в «стеклянный» | стеклянный, оловянный, деревянный — НН |
| 16 | запятая перед каждым «и» | только между частями ССП и при повторе союза |
| 18 | «поэтому», «вдруг» выделены как вводные | они никогда не вводные |
| 20 | пропущена запятая на стыке союзов | запятой нет только перед «то, так, но» |
| 21 | выбраны предложения с тем же знаком, но по разным правилам | определить правило для каждого знака |
| 26 | средство связи отсылает не к предыдущему предложению | связь только с предыдущим |

## Сочинение

| Ошибка | Последствие | Как избежать |
|---|---|---|
| меньше 150 слов | 0 по всем критериям | посчитать слова в черновике |
| позиция автора не сформулирована или неверна | 0 по К1, К2 и К3 | формулировать позицию как ответ на вопрос задания |
| пример без пояснения | минус баллы по К2 | после каждого примера — «Этот эпизод показывает…» |
| связь названа, но не пояснена | 2 балла вместо 3 по К2 | объяснить, **что** противопоставлено или дополнено |
| пересказ текста | комментарий не засчитан | анализировать, а не пересказывать |
| речевые повторы | баллы по К10 | заменять повторы синонимами и местоимениями |

> [!mistake] Перенос в бланк
> В ответах первой части — без пробелов, запятых и лишних символов. В задании 8 и 22 — цифры строго под буквами, в своём порядке.

> [!tip] Совет Зубра
> Отметь в таблице номера, где ошибаешься ты, и повтори именно эти правила за день до экзамена.
