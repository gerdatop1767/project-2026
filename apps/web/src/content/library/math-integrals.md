# Первообразные и интегралы

Первообразная встречается в **№8**: по графику функции найти площадь под ним или значение $F(b) - F(a)$, по формуле первообразной — значения функции.

## Определение

$F(x)$ — первообразная для $f(x)$, если $F'(x) = f(x)$. Все первообразные: $F(x) + C$.

## Таблица первообразных

| $f(x)$ | $F(x)$ |
|---|---|
| $0$ | $C$ |
| $k$ | $kx$ |
| $x^n$, $n \ne -1$ | $\frac{x^{n+1}}{n + 1}$ |
| $\frac1x$ | $\ln\lvert x\rvert$ |
| $e^x$ | $e^x$ |
| $a^x$ | $\frac{a^x}{\ln a}$ |
| $\sin x$ | $-\cos x$ |
| $\cos x$ | $\sin x$ |
| $\frac{1}{\cos^2 x}$ | $\operatorname{tg} x$ |
| $\frac{1}{\sqrt x}$ | $2\sqrt x$ |

**Правила:** первообразная суммы — сумма первообразных; константу выносят; для $f(kx + b)$ первообразная $\frac1k F(kx + b)$.

## Формула Ньютона — Лейбница и площадь

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

Если $f(x) \ge 0$ на $[a; b]$, это **площадь криволинейной трапеции** под графиком.

> [!example] Площадь под параболой
> Найдите площадь фигуры под графиком $y = x^2$ на отрезке $[0; 3]$.
>
> $F(x) = \frac{x^3}{3}$, $S = F(3) - F(0) = 9 - 0 = 9$.

> [!example] Задание формата №8
> Функция $F(x) = x^3 - 3x^2 + 5$ — первообразная функции $f(x)$. Найдите $\int_1^2 f(x)\,dx$.
>
> $F(2) - F(1) = (8 - 12 + 5) - (1 - 3 + 5) = 1 - 3 = -2$.

## По графику $F(x)$

- Значение $f(x_0) = F'(x_0)$ — угловой коэффициент касательной к графику $F$.
- Количество решений $f(x) = 0$ — количество точек экстремума $F$ (и горизонтальных касательных).

> [!mistake] Знак площади
> Если график ниже оси $Ox$, интеграл отрицателен. Площадь — модуль интеграла по частям, где функция сохраняет знак.

> [!mistake] Порядок вычитания
> $F(b) - F(a)$, а не наоборот: верхний предел минус нижний.
