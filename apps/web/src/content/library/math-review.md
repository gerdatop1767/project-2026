# Лист повторения перед экзаменом: математика

Самое нужное на одной странице. Не заменяет теорию — напоминает о ней.

## Алгебра

- $a^m a^n = a^{m+n}$, $(a^m)^n = a^{mn}$, $\log_a(bc) = \log_a b + \log_a c$, $a^{\log_a b} = b$.
- $(a \pm b)^2 = a^2 \pm 2ab + b^2$, $a^2 - b^2 = (a - b)(a + b)$.
- Квадратное уравнение: $D = b^2 - 4ac$, $x = \frac{-b \pm \sqrt D}{2a}$.
- ОДЗ: под корнем $\ge 0$, знаменатель $\ne 0$, аргумент логарифма $> 0$, основание $> 0$ и $\ne 1$.

## Тригонометрия

- $\sin^2 x + \cos^2 x = 1$, $\sin 2x = 2\sin x\cos x$, $\cos 2x = 1 - 2\sin^2 x$.
- $\sin x = a$: $x = \arcsin a + 2\pi k$, $x = \pi - \arcsin a + 2\pi k$; $\cos x = a$: $x = \pm\arccos a + 2\pi k$.

## Производная

- $(x^n)' = nx^{n-1}$, $(e^x)' = e^x$, $(\ln x)' = \frac1x$, $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$.
- $f'(x_0)$ — угловой коэффициент касательной. $f' > 0$ — возрастает.

## Геометрия

- $S_\triangle = \frac12 ab\sin C$, $c^2 = a^2 + b^2 - 2ab\cos C$, $\frac{a}{\sin A} = 2R$.
- $V_{\text{пирамиды}} = \frac13 Sh$, $V_{\text{конуса}} = \frac13\pi r^2 h$, $V_{\text{шара}} = \frac43\pi R^3$.
- Подобие: площади $k^2$, объёмы $k^3$.

## Вероятность

- $P = \frac mn$; «и» — умножение; «или» — сложение несовместных; «хотя бы один» — $1 - P(\text{ни одного})$.
