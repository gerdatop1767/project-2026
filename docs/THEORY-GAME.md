# «Теория на практике»

Мини-игра по математике (`theory-practice`, раздел «Математика» → «Теория»). Ученик тренирует школьную теорию в коротких заданиях. Это не обычный тест: в игре шесть механик.

| Механика | Что видит ученик | Как отвечает |
|---|---|---|
| Продолжи правило (`continue`) | начало правила или теоремы | выбирает верное продолжение |
| Исправь ошибку (`fix`) | утверждение с одной ошибкой | выбирает исправленный вариант |
| Для какой фигуры? (`figure`) | свойство | выбирает фигуру |
| Найди формулу (`formula`) | что вычисляется и обозначения | выбирает верную формулу |
| Верно или неверно (`truefalse`) | утверждение | «Верно» / «Неверно» |
| Соедини пары (`match`) | 3–4 пункта слева | к каждому выбирает пару справа; очки — только если верны все пары |

После каждого ответа показывается короткое пояснение с подписью «Пояснение».

## Банки

Код: `packages/shared/src/theory/`.

- `types.ts` — типы шести механик и банка.
- `geometry.ts` — банк «Геометрия», 81 вопрос. Темы: треугольники, прямоугольный треугольник, признаки равенства, подобие, четырёхугольники, окружность, площади, углы, многоугольники, теоремы.
- `index.ts` — список банков `THEORY_BANKS` и перевод вопроса в вопрос общей системы викторин (`theoryQuizItem`).

Новый раздел (алгебра, тригонометрия, производная, функции, логарифмы, стереометрия, вероятности) — это новый файл с `TheoryBank` и одна строка в `THEORY_BANKS`. Механики, проверка, экран, очки, прогресс и «Мои ошибки» не меняются. `id` вопроса не меняется никогда: по нему хранится прогресс (`theory:<банк>:<id>`).

## Правила для содержания

- Только утверждения школьной программы. Банк сверен с учебником Атанасяна «Геометрия 7–9». Никаких «придуманных» теорем.
- Условия применимости входят в формулировку. Например, «в прямоугольном треугольнике…», «параллелограмм, у которого…», «выпуклого n-угольника».
- Один однозначно верный ответ. Дистракторы не могут оказаться верными при другом прочтении. Например, в «Для какой фигуры?» нет пары «прямоугольник / квадрат», где подходят оба.
- Формулы — в LaTeX (`$…$`), на экране их рисует KaTeX.
- К каждому вопросу — пояснение: почему так, а иногда как проверить.

Тест `packages/shared/src/theory/theory.test.ts` проверяет:
- все шесть механик;
- не меньше 80 вопросов;
- уникальные `id`;
- ответ не совпадает ни с одним дистрактором;
- нет повторов в вариантах;
- пары уникальны слева и справа;
- `$` сбалансированы;
- «верно/неверно» не однобоко;
- каждый вопрос принимается по своему ключу, и любой другой вариант отклоняется.

## Игровая система

Это обычная игра-викторина (`docs/MINI_GAMES.md`):
- раунды с выбором размера;
- 10 очков за верный первый ответ и +20 за раунд без ошибок;
- рекорд;
- «Мои ошибки»;
- прогресс «выучено» — 2 верных ответа подряд.

Опыт (XP) ЕГЭ игра не начисляет: мини-игры его вообще не дают.

Правый столбец «Соедини пары» сервер всегда перемешивает. Ответ — правые пункты в порядке левых, разделитель `MATCH_SEPARATOR`.
