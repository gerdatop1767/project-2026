# Теория по русскому языку: каталог и «Правило» в задании

## Где лежит и как устроено

- **Тексты:** `apps/web/src/content/theory/russian/*.md`. Это присланные владельцем архивы, по одному файлу на материал. Имя файла — `task-NN-<kind>.md`, где `kind` — `theory`, `practice` или `reference`. Каждый файл подгружается отдельным чанком только при открытии, в основной бандл тексты не попадают.
- **Манифест:** `apps/web/src/data/theory/russianTheory.ts` — единственный источник для каталога и для кнопки «Правило».
  - Для каждого номера ЕГЭ (1–27) хранит название, группу, список материалов, необязательную схему и предупреждения.
- **Привязка к заданию:** по паре `subjectId` + `taskNumber`. Её же несёт каждая строка `tasks` в БД и каждый маршрут `task`.
  - Слаги тем как ключ не используются: импортированные варианты называют тему одного номера по-разному. Например, у №21 встречаются `dash-rules`, `colon-rules` и `punctuation-rules`, у №25 — `antonyms`, `phraseology` и `synonyms-search`.
  - Номер задания стабилен во всех импортах русского языка: ЕГЭ-2026 и Дощинский-2027 используют одну нумерацию 1–27.
- **Год:** материалы — учебная выжимка с ориентиром на ЕГЭ-2026 (так помечены в архивах). Это видно на каждом экране.
- **Экраны:**
  - `/theory` (`?n=N`) — «Теория», конспекты.
  - `/materials` (`?n=N`) — «Полезные материалы», справочные списки и практика.
  - Вход: desktop-главная («Учебный центр», карточки «Теория» и «Полезные материалы»), мобильное меню «Теория», прямые ссылки.
- **«Правило» в задании:** кнопка под условием (`ui/Theory/RuleButton`).
  - На телефоне открывается нижней шторкой, на компьютере — модальным окном. Экран задания под ней не размонтируется, поэтому введённый ответ, таймер и подсказка сохраняются.
  - Показывается только для предметов, у которых есть каталог (сейчас только русский). Для №1–2 честно пишет «Материала пока нет».
- **БД, импорт заданий и API не менялись:** это статический контент фронтенда, без CMS и миграций.

## Не исправлено — нужно решение редактора

- **Задание 4, список и исключения:** официальную сверку провести не удалось — `doc.fipi.ru` недоступен из среды разработки.
  - Не проверены построчно: орфоэпический список и фраза «из прежних списков не будут использоваться: нарОст, пОручни, жилОсь…».
  - В интерфейсе стоит предупреждение «ещё не сверен построчно с PDF ФИПИ».
- **Задание 5:** у пары «отличие — признак несходства; различие — несходство» почти одинаковые толкования, разница не объяснена. Предлагается переформулировать по словарю.
- **Задание 6:** «принимать или предпринимать меры» дано как норма, а сочетание «предпринять меры» многие пособия считают ошибкой (смешение «принять меры» и «предпринять шаги»). Вопрос: оставить ли «предпринимать меры»?
- **Задание 6:** «предварительно планировать» как плеоназм — спорно. Классический пример — «заранее планировать».
- **Задание 7:** формат задания описан общо («формат ответа зависит от варианта»). Нужно сверить с демоверсией 2026.
- **Задание 8:** неверный пример «Подъезжая к станции…» выделен жирным, как верные. Оформление вводит в заблуждение; предлагается курсив, как у остальных неверных примеров.
- **Задание 9:**
  - для «равн/ровн» среди исключений нет «ровесник, ровня», зато есть «равняйсь» — спорно;
  - для «гар/гор» не указаны исключения «выгарки, изгарь, пригарь».
- **Задание 14, практика №8:** «Осталась пол-яблока» — нарушено согласование. Предлагается «Осталось пол-яблока».
- **Задание 15:**
  - пример «искренний — искренне» не иллюстрирует Н/НН;
  - не перечислены исключения «нежданный, негаданный, неслыханный, невиданный…».
- **Задание 16:** правило «после перечисления перед обобщением — тире» проиллюстрировано примером «Всё: книги, тетради, ручки — лежало», где обобщающее слово стоит до перечисления. Предлагается добавить пример под правило.
- **Задание 20 (11–20), практика №3:** «что хотя устала, но продолжит» — конструкция «хотя… но» считается стилистически небезупречной. Оставлено как в архиве, вопрос к редактору.
- **Задание 22:**
  - пример метафоры «лес уснул» — по сути олицетворение (как и «ветер шепчет»);
  - в практике №1 «дождь стучал в окно» как олицетворение спорно: «стучать» здесь можно понимать буквально.
- **Задание 27:** объём «не менее 150 слов» и критерии нужно сверить с демоверсией 2026.

## Как добавить или поправить материал

1. Положить или изменить файл `task-NN-<kind>.md` в `src/content/theory/russian`.
2. Добавить его в `materials` нужного номера в `russianTheory.ts`.
3. `pnpm --filter @zybrilka/web test`: тест проверит, что каждый файл указан в манифесте, а каждый материал манифеста есть на диске.
