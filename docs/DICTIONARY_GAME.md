# Мини-игра «Словарные слова и исключения»

Одна игра (`gameId = dictionary`, маршрут `/games/dictionary`), номер задания выбирается внутри неё.

## Откуда слова

Источник — `packages/shared/src/dictionaryWords.ts`. Слова записаны вручную по правилам орфографии, которые проверяют задания 9–15, и сверены с орфографическим словарём.

Формат строки:
- для букв: `пропуск|ответ|другой вариант|!|пояснение|приём` (`!` — исключение);
- для написаний: `(НЕ)ВЕЖДА|невежда|слитно|…`.

Вопросы из задач не вырезаются и не генерируются. Поэтому число вопросов — ровно то, что в таблице: раунд больше этого не собирается (409 `not_enough_questions` с реальным числом).

Приём запоминания — подсказка для памяти, а не происхождение слова. Так он и подписан.

## Пять видов вопросов

Вопросы строятся в `packages/shared/src/dictionaryGame.ts`, детерминированно: id вопроса стабилен между запусками.

1. **Вставь букву / Как пишется** — пропуск в слове или выбор «слитно / раздельно / через дефис».
2. **Как пишется правильно** — верное написание среди неверных.
3. **Найди ошибку** — одно слово группы написано неверно, остальные — верно.
4. **Найди исключение** — одно исключение среди слов, пишущихся по правилу; только для слов-исключений.
5. **К какой группе** — по слову определить правило.

Тесты (`dictionaryWords.test.ts`) проверяют:
- пропуск, заполненный ответом, даёт ровно слово;
- у каждого вопроса верный ответ есть среди вариантов, варианты не повторяются;
- в «Найди ошибку» ровно одно неверное написание;
- нет повторов слов;
- у каждого слова есть объяснение.

## Раунд и очки

Всё как у остальных викторин (docs/MINI_GAMES.md § Сессии, § Рейтинги):
- раунд — серверная сессия, режим записан как `задание:группа:режим`;
- «Продолжить игру» работает на любом устройстве, «Новая игра» закрывает незаконченный раунд;
- засчитывается только первый ответ на вопрос: 10 очков за верный, +20 за раунд без ошибок; итог считает сервер, повторный `finish` ничего не добавляет;
- в раунде сначала разные слова: одно слово возвращается другим видом вопроса, только если раунд длиннее числа слов;
- ответ с ошибкой один раз возвращается через три вопроса того же раунда.

**Слово выучено**, когда на какой-то его вопрос дано два верных ответа подряд.

**«Мои ошибки»** — вопросы задания, на которые последний ответ был неверным (нужен вход).

**Рейтинг** — общий для игры: «Лучший результат» и «Всего очков». Рекорд по каждому заданию показан на его карточке.

## API

- `GET /games/dictionary/summary` — задания, группы, число слов и вопросов; для вошедшего — выучено и рекорд.
- `GET /games/dictionary/reference/:task` — справочник задания: слова в правильном написании, правило группы, объяснение, приём запоминания.
- `GET /games/dictionary/round?task&category&mode&size`, `POST …/answer`, `…/finish`, `GET …/active`, `POST …/abandon`.

## Справочник

Внизу экрана игры: слова выбранного задания по группам с правилом. По нажатию на слово — объяснение и приём запоминания.

Поиск ищет во всех заданиях. Регистр, «ё/е» и дефисы не важны.
