# Баллы ЕГЭ за вариант

Код:
- `packages/shared/src/examScoring.ts` — правила, шкалы, снимок, расчёт;
- `apps/api/src/modules/learning/learningSession/service.ts` (`scoreAttempt`);
- экран `apps/web/src/screens/VariantAttempt/PrimaryPoints.tsx`.

Считается **только полный вариант** — сессия варианта из «Тренировки → Вариант». Случайная тренировка, «Мои ошибки» и задания по номеру баллов ЕГЭ не получают.

## Правила (первичные баллы)

Формат экзамена задаётся коллекции полем `examFormat`.

| Формат | Статус | Заданий | Максимум | Часть 2 |
|---|---|---|---|---|
| `ege-math-profile-2026` | official (спецификация ФИПИ 2026) | 19 | 32 | 13=2, 14=3, 15=2, 16=2, 17=3, 18=4, 19=4 |
| `ege-math-profile-2027` | **project** (проект КИМ 2027, ФИПИ, август 2026) | 20 | 33 | 14=2, 15=3, 16=2, 17=2, 18=3, 19=4, 20=4 |

Часть 1 — по 1 баллу. Как начисляется:
- **Часть 1 — точно:** верный ответ даёт полный балл.
- **Часть 2 — только по ответу (оценка).** Решение и доказательство мы не проверяем:
  - задача с доказательством (2027: №15, №18) даёт 2 из 3 за верный ответ пункта б);
  - остальные дают полный балл за верный ответ;
  - последняя задача а/б/в даёт 1 + 1 + 2 по пунктам.

  На экране это подписано.
- Считается **первый ответ** на задание в этой попытке: повтор — не второй шанс. Пустой ответ — 0. Двойного счёта нет. Открытие задания и повторный вход в вариант ничего не добавляют.
- Незавершённая попытка — **«Предварительно»**.
- Задания варианта на проверке (2027 №17) не предлагаются и не дают баллов. Пишется «доступно 31 из 33».

## Снимок правил в попытке

При старте варианта в `learning_sessions.scoring` (jsonb, миграция 0035) копируются:
- id и статус правил;
- максимум экзамена;
- граница частей;
- для каждого задания — номер и правило;
- номера, которых нет в варианте;
- id действующей шкалы.

Изменение правил или шкалы старые попытки **не пересчитывает**. Попытки, начатые до появления снимка, считаются по текущим правилам своего формата с пометкой «посчитано по действующим правилам».

## Шкала перевода в тестовые баллы

`EXAM_SCALES` — отдельный реестр. Для каждой шкалы хранятся:
- id, формат, год;
- статус `official` или `approximate`;
- источник, дата;
- таблица `testByPrimary`.

**Сейчас реестр пуст:**
- ЕГЭ-2027 ещё не проводился, его шкала утверждается после экзамена;
- опубликованные таблицы 2026 расходятся между собой начиная с 9 первичных баллов, а официальный документ из среды недоступен.

Поэтому экран показывает только первичные баллы и причину: «Официальная шкала перевода ЕГЭ-2027 ещё не опубликована…».

Правила:
- Формула или линейная пропорция не используется **никогда**.
- Проходной балл вуза — не шкала перевода.

Чтобы добавить шкалу:
1. Внести запись в `EXAM_SCALES`: источник, дата, статус. `approximate` показывается как «Оценка приблизительная, официальная шкала может отличаться».
2. Новые попытки получат её id в снимок, старые останутся без пересчёта.
