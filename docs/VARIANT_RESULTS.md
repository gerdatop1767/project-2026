# Результаты вариантов

## Что видит пользователь

- **После последнего задания варианта** — экран результата именно этой попытки.
- **«Статистика» → «Статистика вариантов»:** каждая карточка истории кликабельна и открывает свою попытку (`/statistics/variants/<id попытки>`), а не последнее решение.

Что на экране результата:
- **Счёт:** верно / неверно / пропущено / не решалось, точность (верно от отвеченных).
- **Время:** только если оно реально измерялось. Если измерено не для всех ответов — подпись «Время (N из M)».
- **По номерам и по темам** — тема показывается, только если у задания она есть.
- **«Стоит повторить»:** неверные и пропущенные задания, по нажатию открывается задание.
- **Каждое задание:** ответ пользователя, правильный ответ, разбор, кнопка «Открыть задание».
- **Незавершённая попытка** показывает честные частичные цифры и кнопку «Продолжить вариант».

## Как считается

- **Попытка** — это строка `learning_sessions` с `variant_id`. Несколько попыток одного варианта — несколько строк.
- **Связь ответа с попыткой** — `attempts.learning_session_id` (миграция 0033).
  - Клиент присылает `sessionId` вместе с ответом.
  - Сервер привязывает ответ, только если это сессия того же пользователя, она ещё идёт и выдавала это задание (`sessionForAttempt` в `apps/api/src/modules/tasks/repo.ts`). Иначе ответ сохраняется без привязки.
- **Исход задания решает первый ответ в попытке** (как на экзамене). Повторы видны в «попыток: N», но счёт не меняют.
- **Попытки до миграции 0033** (без привязанных ответов) считаются по окну времени: непривязанные ответы на её задания между началом и завершением. На экране — пометка «Попытка из старой версии».
- **Исходы:** `skipped` — задание выдавалось, но ответа нет; `not_reached` — до задания не дошли.

## API

`GET /api/v1/progress/variants/:sessionId` — только для владельца. Чужая или несуществующая попытка — `404`, без сессии — `401`. Ответ: `VariantAttemptDetail` (`packages/shared/src/learning/learningSession.ts`).
