# Ежедневные напоминания в Telegram

## Для пользователя

- **Где настроить:** «Уведомления» — меню на ПК, Профиль на телефоне, адрес `/notifications`.
  - переключатель «Ежедневное напоминание»;
  - время;
  - часовой пояс (по умолчанию — пояс устройства).
- **Сообщение:** «📚 Время потренироваться! Реши несколько заданий ЕГЭ сегодня.» Под ним кнопки «Начать тренировку» (`/training`, в Telegram открывается как Mini App) и «Отключить напоминания».
- **Как отключить:**
  - на сайте;
  - кнопкой под напоминанием;
  - командой `/reminders_off` в боте.

## Связь аккаунта с Telegram

Напоминание уходит в личный чат с ботом того Telegram, который привязан к аккаунту (`auth_identities`, provider `telegram`).

- **Вход через Mini App:** привязка уже есть.
- **Иначе — «Привязать Telegram» на экране «Уведомления»:**
  1. API выдаёт одноразовый токен: `POST /me/telegram/link`. В базе хранится только SHA-256, срок 15 минут.
  2. Сайт открывает `t.me/zybrilka_bot?start=link_<token>`.
  3. Бот принимает токен вместе с id отправителя, который подтверждает сам Telegram: `consumeTelegramLinkToken` в `packages/db/src/telegramLink.ts`.
- **Правила привязки** общие для всех путей (`addIdentity`). По имени или username аккаунты не связываются никогда.
  - Telegram, занятый другим аккаунтом, не переносится.
  - Второй Telegram к аккаунту не добавляется.
- **Риск:** привязанный так Telegram становится и способом входа (как при входе через Mini App). Поэтому ссылка одноразовая и короткоживущая; отвязать Telegram можно в профиле.

## Отправка

Отправляет `ReminderScheduler` (`apps/worker/src/reminders/scheduler.ts`) в существующем цикле задач worker, раз в минуту. Отдельного планировщика нет.

- **Кому:** включено, Telegram привязан, бот запущен (`telegram_bot_chats`) и не заблокирован. Остальным ничего не отправляется: Telegram и не позволяет боту писать первым.
- **Когда:** с выбранной минуты по местному времени пользователя (IANA-пояс) и не позже чем через 2 часа. Если worker простоял дольше, напоминание за этот день пропускается.
- **Не больше одного в день:** перед отправкой «захватывается» строка `reminder_deliveries` с уникальной парой (пользователь, местная дата). Повторный запуск, перезапуск worker или второй экземпляр находят строку и ничего не шлют.
- **Ошибки:**

  | Что случилось | Что делает worker |
  |---|---|
  | Сообщение точно не дошло до Telegram (сеть) | повтор в пределах окна, до 5 попыток |
  | 429 | повтор после паузы |
  | «Возможно, показано» (таймаут после отправки) | `uncertain`, повтора нет |
  | Бот заблокирован (403) | `unreachable`, чат помечается заблокированным |
  | Worker упал во время отправки | при старте `sending` → `uncertain` |

## Таблицы (миграция 0032)

- `reminder_settings` — включено, минута суток, часовой пояс.
- `reminder_deliveries` — журнал по дням.
- `telegram_link_tokens`.
