## Как читать
- **«Номер ЕГЭ»** — номер в актуальной редакции (ЕГЭ-2027 = ЕГЭ-2026). Задание старой редакции Ященко-2027 учтено там, где его тема стоит сегодня. Например, их №13 «Финансы» входит в строку №16, их №6 «Случайные величины» — в отдельную строку «старая редакция».
- **«Навык»** — тема спецификации ФИПИ (`EXAM_TOPICS` в `packages/shared/src/examSpecs.ts`). Ключ навыка не зависит от варианта и года.
- **«Связано с навыками»** — у задания есть строка в `task_skills`. Связи создаёт `syncTaskSkills`.
- **Задания на проверке** (`needs_review`) тоже связаны с навыком. Ученикам их не выдают ни рекомендации, ни тренировки, ни каталог.
- **Задание старой редакции №9** проверяет две темы (`math.derivative-graphs` и, частично, `math.derivative-investigation`). Оно связано с обеими, а в таблице считается по первой.

## Если появится «без навыка»
Это задание с номером, которого нет в спецификации его редакции: новый формат экзамена или ошибка импортёра.
- Синхронизация не выдумывает для него тему. Задание пишется в лог API (`learning: task without an EGE skill`) и в эту таблицу (строка «нет позиции в спецификации»).
- Исправление:
  - если ошибся импортёр — исправить номер в нём;
  - если вышла новая спецификация — добавить редакцию и темы в `examSpecs.ts`.
- После деплоя связь появится сама.
