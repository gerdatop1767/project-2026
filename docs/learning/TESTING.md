# Learning Engine — тесты

Запуск:

```
pnpm test                                                             # всё
npx vitest run --project shared packages/shared/src/learning          # формулы
npx vitest run --project api apps/api/src/modules/learning            # API и сценарии
npx vitest run --project web apps/web/src/ui/LearningEngine           # компоненты
```

Интеграционные тесты идут на настоящем контенте, а не на выдуманных заданиях. Тестовая база — `createFullContentTestDb()` (`packages/db/src/testing.ts`):
- математика ЕГЭ-2026, варианты 1–10;
- Ященко-2027, варианты 1–25;
- русский язык ЕГЭ-2027, варианты 1–18.

Это реальные импортёры и реальные метаданные. Она поднимается в PGlite за несколько секунд.

## Проверка в браузере (локальный стенд)
Стенд: PostgreSQL 16 с production-контентом, собранные API и веб.

- **Рекомендации и навыки:** учебный центр показывает рекомендации, «Статистика» — навыки по номерам. Проверено на 320, 375 и 1440 px: без горизонтальной прокрутки и ошибок страницы.
- **Тренировка из рекомендации** («Начать»): на задании видна причина выбора, после ответа — блок «Насколько сложным…»; оценка сохраняется.
- **Пересчёт при старте API:** статистика навыков 121 ученика стенда восстановлена из истории (2314 строк).
