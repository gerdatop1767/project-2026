# Умная тренировка с настройкой

Экран «Тренировка» → «Умная тренировка». Ученик сам решает, что тренировать; задания подбирает Learning Engine (`ALGORITHMS.md` § 3–4). Отдельной системы подбора нет.

## Что выбирает ученик

| Настройка | Значения | Что меняет в подборе |
|---|---|---|
| Предмет | математика, русский язык (у Learning Engine есть навыки только этих предметов) | `subjectId` сессии |
| Тип тренировки | см. таблицу режимов | план: какие навыки и какие корзины |
| Темы | для «Конкретных тем» — одна или несколько тем предмета | навыки плана |
| Количество | 5 / 10 / 15 / 20 или своё, 3–50 | `total` сессии |
| Сложность | лёгкие / средние / сложные / смешанные | `plan.difficulty` = 1 / 2 / 3; «смешанные» — сложность по освоению навыка (`targetDifficultyFor`) |
| Только нерешённые | вкл/выкл | `unseenOnly`: задания, на которые ученик ещё не отвечал |

Сложность — это цель подбора, а не жёсткий фильтр. Подборщик ставит выше задания, чья эффективная сложность (авторская плюс оценки других учеников) ближе к выбранной. Поэтому на экране она подписана «ближе к лёгким».

Распределения «новые / из ошибок / на повторение / по слабым темам» отдельной настройкой нет: это и есть режимы. Ручные доли не вводятся, чтобы не было настроек, которые подбор понимал бы иначе, чем ученик.

## Режимы (`packages/shared/src/learning/smartTraining.ts`)

| Режим | Навыки плана | Корзины (`weak / mistakes / stale / strong`) |
|---|---|---|
| Весь предмет (`subject`) | все темы с номером, по одной теме на задание, пока темы не кончатся | корзина темы по состоянию ученика в ней |
| Конкретные темы (`topics`) | только выбранные, включая ещё не начатые | обычная смесь 50/25/15/10 внутри выбранных тем |
| Проблемные темы (`problems`) | до 8 тем из `problemSkills` | 60 / 40 / 0 / 0 |
| По моей статистике (`stats`) | весь предмет | 45 / 35 / 20 / 0 |
| Смешанная (`mixed`) | весь предмет | 35 / 25 / 25 / 15 |

**Проблемная тема (`problemInfo`)** — по ответам самого ученика. Подходит тема, где верно хотя бы одно:
- уровень `weak`;
- есть открытые ошибки;
- есть повторные ошибки;
- тренд вниз;
- в последних ответах половина или больше неверных.

Тема с менее чем 3 ответами и без открытой ошибки не оценивается.

Вес темы складывается из:
- 100 − освоение;
- доли ошибок;
- доли ошибок в последних ответах;
- открытых и повторных ошибок;
- падения;
- ошибок после разбора;
- давности.

Ученик видит причины: «точность 38%», «не исправлено ошибок: 3» и т. п.

**Только выбранные темы.** Слоты плана называют только навыки плана. `pickForSlot` при нехватке задач у навыка переходит только к другим навыкам этого же плана. Поэтому при «Проблемных темах» или выбранных темах задание из другой темы не попадёт.

## Проверка количества

`GET /me/learning/smart-setup?subject=` отдаёт по каждой теме:
- освоение (null без ответов);
- уровень;
- число доступных заданий;
- открытые ошибки;
- признак проблемы.

Также в ответе есть список проблемных тем и число заданий предмета.

На экране число доступных заданий для выбранных тем — сумма по темам, это верхняя граница: одно задание может относиться к двум темам. Если выбрано больше, экран предлагает «Выбрать N».

Сервер считает точно (`availableTasksFor`: различные опубликованные задания тем, с «Только нерешёнными» — без попыток). Если заданий меньше выбранного, он отвечает `409 { error: 'not_enough_tasks', available }`, и экран предлагает «Начать с N».

## API

`POST /me/learning/sessions` с `smart: { mode, skillKeys?, difficulty? }` и `subjectId`, `limit` 3–50:
- `422 no_problem_topics` — у ученика нет проблемных тем;
- `422 no_topics` — темы не выбраны;
- `422 unknown_topic` — тема не из этого предмета;
- `409 not_enough_tasks` — заданий меньше, чем выбрано;
- `400` — тема другого предмета, `limit` вне 3–50, вместе с `focusSkill` или `mix`.

Обычный старт без `smart` (рекомендации, планы обучения) не изменился, кроме верхнего предела `limit`: 50 вместо 10.
