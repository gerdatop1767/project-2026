# Вход и регистрация по почте — сняты

Регистрация по почте, письма подтверждения, восстановление пароля, вход по одноразовой ссылке и **вход по почте и паролю удалены**. Отправки писем (SMTP) в проекте нет. Войти можно только через VK ID, Яндекс ID или Telegram — см. [`YANDEX_ID.md`](./YANDEX_ID.md).

- **Маршруты.** `/auth/magic-link`, `/auth/verify`, `/auth/register*`, `/auth/password/*`, `/auth/login` больше не существуют и отвечают 404.
- **Данные.** Таблицы `email_credentials` и `magic_link_tokens` с их данными не тронуты. Миграция для их удаления не делалась.
- **Переменные `SMTP_*`.** Больше не читаются.

Что делать с уже существующими email-аккаунтами — в разделе «Аккаунты с почтой» файла [`YANDEX_ID.md`](./YANDEX_ID.md).
