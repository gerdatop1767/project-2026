# Регистрация по почте — снята

Регистрация по почте с письмом подтверждения, восстановление пароля по почте и вход по одноразовой ссылке **удалены** вместе с отправкой писем (SMTP). Им на смену пришёл вход через Яндекс ID — см. [`YANDEX_ID.md`](./YANDEX_ID.md).

Что осталось:

- **Вход по паролю.** Аккаунты, у которых уже есть почта и пароль, входят как раньше: `POST /api/v1/auth/login`, ссылка «Уже есть аккаунт с почтой и паролем? Войти». Писем это не требует.
- **Данные.** Таблицы `email_credentials` и `magic_link_tokens` с их данными не тронуты. Миграции `0026_email_password.sql` откат не нужен.
- **Маршруты.** `/auth/magic-link`, `/auth/verify`, `/auth/register*`, `/auth/password/*` больше не существуют и отвечают 404.
- **Переменные `SMTP_*`.** Больше не читаются.

Что делать с аккаунтами, у которых нет пароля, — в разделе «Аккаунты с почтой» файла [`YANDEX_ID.md`](./YANDEX_ID.md).
