# Мини-игры

## Для пользователя

- **Вход:** «Задания» → карточка «Мини-игры» (`/games`) → карточка игры → «Играть».
- **Первая игра — «Ударения»** (`/games/stress`), задание 4 ЕГЭ по русскому:
  - Слово показывается без ударения, «ё» пишется как «е» (иначе ударение видно сразу). Нужно нажать на ударную гласную. Нажимаются только гласные, кнопки не меньше 44 px.
  - Проверяет сервер: в вопросе правильного ответа нет. После ответа видно правильную форму («тОрты»), неверный выбор зачёркнут.
  - **Ошибка:** «Повторить слово» сразу, и слово ещё раз вернётся через 3 вопроса (один раз за раунд). Итог раунда считает только первый ответ на каждое слово.
  - **Режимы:**
    - «Все слова» — сначала невыученные, выученные только для добивки раунда;
    - «Мои ошибки» — последний ответ был неверным;
    - «Сложные слова» — где больше всего ошибок.

    Раунд — 20 слов, порядок перемешивается на сервере (`crypto.randomInt`).
  - **Прогресс** (для вошедших): выучено N из M (выучено = 2 верных ответа подряд), верно / неверно / точность, сложные слова, ответы по дням за 2 недели. «Продолжить тренировку» продолжает с сохранённого прогресса.
  - **Гость** играет без сохранения. «Мои ошибки» и «Сложные слова» просят войти.

## Игры-викторины (17 игр)

**Раздел.** Те же «Мини-игры» (`/games`), без нового раздела:
- две вкладки — «Русский язык» (16 игр вместе с «Ударениями») и «Математика» (2 игры); выбор запоминается (`zybrilka.miniGames.category`);
- внутри вкладки игры сгруппированы по темам: Орфография, Пунктуация, Нормы языка, Текст и лексика, Первая часть;
- у карточки — номер задания ЕГЭ и настоящее число вопросов.

Игра открывается по адресу `/games/:gameId`.

**Откуда вопросы.** Каждый вопрос вырезан из настоящего опубликованного задания ЕГЭ: его условие, его ключ, его же разбор. Разборщики — `packages/shared/src/quizGames.ts`.
- Ничего не придумывается. Задание, условие или ключ которого не разбирается однозначно, вопросов не даёт.
- Объяснение — кусок разбора задания именно про этот ряд, место, фрагмент или предложение. Кусок обрывается на маркере любой другой позиции, так что чужие разборы не попадают. Если разбор вырезать не удалось, показывается «Правильный ответ — по ключу задания ЕГЭ».
- Повторы (одно и то же задание в разных сборниках) убираются.

| Игра | id | Задание | Вопрос | Вопросов* |
|---|---|---|---|---|

\* На полном наборе контента: три сборника по русскому (Дощинский 18 вариантов, «36 вариантов» 2026 и 2027) и математика ЕГЭ-2026 и Ященко-2027. Число считается при запуске (`/games` → `questionCount`).

**Ограничения:**
- Количество вопросов отличается от прежнего отчёта: тогда на стенде был только сборник из 18 вариантов, теперь в базе три сборника по русскому.
- Часть заданий вопросов не даёт, потому что не разбирается однозначно. Например, в №22 подходят только задания, где перечень средств и ключ сходятся (61 из 90). В №5 и №7 — только те, где ключ однозначно указывает на одно выделенное слово.
- В «Грамматических нормах» у предложений без ошибки нет своего разбора в задании. Пояснение там выведено из ключа: «По ключу задания в этом предложении нет ни одной из пяти ошибок…».
- Математика — только задачи без рисунка с ответом-числом.

**Механика:**
- **Раунд.** 10 вопросов, сначала невыученные; порядок и варианты ответа перемешивает сервер. Ключа в вопросе нет — проверяет сервер.
- **Засчитывается первый ответ.** После него вопрос блокируется и показываются правильный ответ и разбор. Второй ответ на тот же вопрос в этом раунде не записывается; повторная отправка (тот же `clientAnswerId`) засчитывается один раз.
- **Очки.** 10 за верный ответ и +20 за раунд без ошибок (`quizRoundScore`). Лучший раунд хранится по `mini_game_sessions.first_try_correct`.
- **Прогресс** (для вошедших): выучено N из M (2 верных ответа подряд), точность, «на повторение», лучший раунд.
- **«Мои ошибки»** — вопросы, последний ответ на которые был неверным. Повторное прохождение — «Ещё раунд».
- **Гость** играет без сохранения. «Мои ошибки» и прогресс просят войти.
- **Таблицы.** Используются только `mini_game_answers`, `mini_game_item_progress`, `mini_game_sessions`. Таблицы `attempts`, `mistakes`, XP и `learning_sessions` не трогаются — это проверено тестом. Миграций нет.
- **API.** `GET /games/quiz/:gameId/round?mode=all|mistakes&size=10`, `POST …/answer`, `POST …/finish`, `GET …/progress`. Лимиты — как у «Ударений».

## Словарь ударений — источник и статус проверки

**Источник:** «Орфоэпический список – 2026» ФИПИ, напечатанный в «Навигаторе самостоятельной подготовки к ЕГЭ 2026. Русский язык. Фонетика и орфоэпия», с. 1–5.
- PDF от 2026-02-02, 7 страниц, SHA-256 `6e1b6dca…f389`.
- Извлечённый список с номерами страниц: `docs/sources/fipi-orthoepic-2026.json`; скрипт извлечения: `docs/sources/extract_fipi_orthoepic.py`.
- Полный отчёт сверки: `docs/imports/stress-dictionary-audit-2026.md`.

| Что | Статус |
|---|---|
| Состав | **Совпадает со списком 2026 один к одному:** 219 словоформ (в PDF напечатано 220 — «красИвее» дважды, как прилагательное и как наречие). Каждой записи `fipi_verified`, у каждой в `data.ts` указаны страницы PDF. |
| Ударение | Ровно как отмечено в списке. Если в экзамене слово стоит в другой форме, ударение сохраняется (примечание ФИПИ, с. 5–6). |
| Исключённые ФИПИ слова | нарОст, пОручни, жилОсь, навралА, совралА, сорИт, кормЯщий, поднЯв, донЕльзя, зАтемно (с. 5–6) — в словаре их нет. |
| Формы и омографы | Формы с разным ударением — отдельные записи: «зАнял / занялА / зАняли», «лОктя / локтЕй». «Отзыв» (о книге) и «отзЫв» (посла) — две записи с пояснением значения, как в списке. |
| Проверка заданий проекта | Задание 4 вариантов Дощинского-2027 сверено с официальным списком (`stressDictionary/audit.ts`): найдено 9 расхождений; словарь по ним не менялся. Ключи V1, V2, V7, V14, V18 исправлены, V10, V15, V16 на ручной проверке (`docs/imports/task-4-audit-2027.md`). |

**Тест** `stressDictionary.test.ts` проверяет, что `data.ts` и извлечённый список совпадают: формы, порядок и страницы. Если меняется официальный список, обновите JSON и `data.ts` вместе.

## Импорт и проверка данных

- **Валидация** (`validateStressEntries`, `packages/shared/src/miniGames.ts`):
  - ровно одна заглавная буква, и это гласная;
  - не меньше двух гласных;
  - «ё» всегда ударная;
  - известная часть речи;
  - нет дублей: одна и та же ударная форма дважды запрещена, разные формы — нет.
- **Импорт:** `pnpm --filter @zybrilka/db db:import:stress` (в production — `node node_modules/@zybrilka/db/dist/stressDictionary/import.js`).
  - Идемпотентен: upsert по ключу формы, id слов (и прогресс игроков) сохраняются.
  - Слово, убранное из данных, деактивируется, а не удаляется.
  - Если хоть одна строка невалидна, импорт ничего не пишет.
- **Подключение к деплою:** в `infra/docker-compose.yml` (файл из репозитория) импорт — последний шаг сервиса `sync-content`, через `&&` после импортов вариантов.
  - Выполняется после `migrate` и `sync-subjects` и до запуска `api` / `worker`: у них `depends_on: sync-content: service_completed_successfully`.
  - Ошибка импорта даёт ненулевой код, `sync-content` падает, `api` / `worker` не стартуют. Проверено тестом `packages/db/src/deploySyncContent.test.ts`.
  - Как подключить на VPS (там свой `docker-compose.deploy.yml`) — в `docs/DEPLOYMENT.md`, раздел «Словарь ударений на VPS».

**Проверено на тестовой PostgreSQL 16** тем же бандлом, что кладётся в образ (`pnpm --filter @zybrilka/api deploy --prod`):
- чистая база → миграции → импорт: 219 форм официального списка, 2 источника;
- переход со старого словаря (222) на официальный: 202 id сохранены, 17 новых, 20 деактивированы, прогресс и история ответов на месте;
- повторный импорт: id слов, прогресс игроков и журнал ответов не изменились (сверка по контрольным суммам);
- слово, убранное из данных, стало `active = false`; после возврата в данные — тот же id, прогресс по нему на месте;
- нет `DATABASE_URL`, база недоступна или не применены миграции → код выхода 1.

## Как устроено

- **Реестр игр** — `MINI_GAMES` в `packages/shared/src/miniGames.ts`.
  - Новая игра: запись в реестре, свой модуль API и экран, строка в `gameRoutes` (`apps/web/src/screens/MiniGames/MiniGames.tsx`).
  - Хаб, карточки и хранение прогресса общие.
- **Таблицы** (миграция 0034):
  - `stress_sources`, `stress_words`;
  - `mini_game_answers` — каждый ответ, `(user_id, client_answer_id)` уникален: повтор запроса засчитывается один раз;
  - `mini_game_item_progress` — по (пользователь, игра, слово): верно / неверно / серия, обновляется в той же транзакции, что и ответ.
- **API** (`apps/api/src/modules/games`):
  - `GET /games`;
  - `GET /games/stress/round?mode=&size=` — `mistakes` / `hard` только с входом;
  - `POST /games/stress/answer` — проверка на сервере, запись только для вошедших;
  - `GET /games/stress/progress` — только с входом.
- **Защита:**
  - лимиты на аккаунт / IP;
  - cross-site POST отклоняется;
  - всё действует только на аккаунт сессии.
