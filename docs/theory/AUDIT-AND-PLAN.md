## 2. Предлагаемая архитектура теории (этап 9) — без изменений БД

Теория — это контент, а не данные пользователя. Её версия должна жить в Git рядом с кодом, как сейчас у русского. **Миграции не нужны**, пользовательские данные не затрагиваются.

```
packages/shared/src/examSpecs.ts      — год × номер → тема (сделано)
apps/web/src/content/theory/
  math/<topicKey>/index.md            — общая теория темы
  math/<topicKey>/<subtopic>.md       — подразделы: типы задач внутри номера
  russian/<topicKey>/…                — то же; существующие файлы task-NN-* переезжают без изменения текста
apps/web/src/data/theory/manifest.ts  — темы → разделы → подразделы, источники, рисунки
apps/web/src/ui/Theory/figures/       — точные SVG-чертежи (переиспользуют CoordinatePlaneBase/FunctionGraphSVG)
```

- **Привязка к заданию:** задание → (`subjectId`, год из `sourceYear`, `taskNumber`) → `topicKeysForTask()` → теория. Кнопка «Правило» начнёт работать и для математики, с правильной темой для 2026 и для 2027.
- **Иерархия:** тема (общая теория) → раздел правила → частный случай → примеры. Так в одном номере живут разные правила.
- **Источники:** у каждой темы — список `{название, ссылка, дата, что подтверждает}`. Выдуманных ссылок нет: если источник не открылся, это пишется.
- **Разметка теории:** расширение безопасного разборщика без HTML:
  - формулы `$…$` через существующий KaTeX;
  - блоки `> [!remember]`, `> [!mistake]`, `> [!exam]`, `> [!tip]` — совет с Зубром, редко;
  - встраивание рисунка `![[figure-id]]` из реестра SVG.
- **Обновление:** текст меняется коммитом. Ключи тем стабильны, поэтому закладки и ссылки не ломаются.

**Отображение формул (14.11.2026).** В теории длинная строчная формула разбивается после знаков отношения верхнего уровня (=, ≤, ⇒, ⟺), и строка переносится по ним. Раньше такая формула на телефоне превращалась в полосу с горизонтальной прокруткой. Это касается только текстов теории; формулы в заданиях отображаются как прежде. Отдельные длинные куски без знаков отношения на ширине 320 px по-прежнему прокручиваются, с подсказкой у края.
