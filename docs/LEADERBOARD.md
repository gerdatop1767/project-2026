# Рейтинг

`GET /api/v1/leaderboard?period=today|week|all&subject=<id>&limit=<0..100>` — только для вошедших пользователей (без сессии 401). Код: `apps/api/src/modules/leaderboard`, типы ответа: `packages/shared/src/leaderboard.ts`.

## Как считается

- **Очки** — опыт (XP), полученный за период (и по предмету, если он выбран). Сумма `xp_events.amount`, предмет — через `xp_events.source_id → tasks.subject_id`. XP даётся один раз за задание и за повторение не раньше чем через неделю (docs/XP.md), поэтому повторением лёгких заданий рейтинг не накрутить — в отличие от простого числа решённых.
- **Место** — `rank()` по очкам: при равенстве очков место общее (1, 1, 3). В рейтинге только те, у кого за период больше 0 очков.
- **Решено задач** — разные задания с хотя бы одним верным ответом за период.
- **Точность** — верные ответы / все ответы за период. Так же точность считается в остальной статистике.
- **Уровень** — общий, по всему опыту (`user_xp.total_xp`), независимо от периода.
- **Периоды:**
  - «Сегодня» — с полуночи по Москве (как серии и дневная статистика);
  - «Неделя» — последние 7 суток (скользящее окно, без пустого рейтинга по понедельникам);
  - «Всё время» — без ограничения.
- **`me`** приходит всегда, даже если пользователя нет в топе. `rank: null` — за период ещё нет очков.

## Приватность

В ответе нет id, email, ссылок на фото и полной фамилии. Имя — пользовательское имя профиля; если его нет — имя и первая буква фамилии («Анна С.»); если нет и имени — «Участник». Аватар в рейтинге — буква на цветном круге; цвет (`avatarHue`) вычисляется хешем и не раскрывает id. Своё фото пользователь видит только в своей строке, из собственного профиля.

## Где показывается

- Страница «Рейтинг» (мобильная и десктопная): переключатель периода, фильтр по предмету, тройка лидеров, список, своя строка выделена.
- Место в рейтинге за неделю по всем предметам:
  - на мобильной главной — рядом с решёнными заданиями и процентом правильных;
  - на десктопе — в шапке рядом с серией и уровнем.

  Запрос `limit=0` возвращает только `me`; он загружается один раз вместе с серией и уровнем и обновляется после ответа на задание.
