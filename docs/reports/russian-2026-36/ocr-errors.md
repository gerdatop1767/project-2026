## Типичные ошибки OCR

- Номера предложений: «(З)» → «(3)», «(И!1» → «(11)», «(7Т)» → «(7)», «{1)» → «(1)».
- Цифры вместо букв: «0б», «0» → «об», «О».
- Римские цифры: «ХУШ» → «XVIII», «ХХ» → «XIX» (по скану).
- Точка, распознанная как запятая, перед номером следующего предложения: «лай, (2)» → «лай. (2)». Сборщик данных проверяет каждое такое место и отказывается собирать вариант с запятой перед номером.
- Склейка строк с дефисом: «сестры-Евгения», «Чехову-Искренно» → восстановлены по скану.
- Лишние кавычки (‘ ’ ‚) и «©» из фона: удалены. В сборщик добавлена проверка этих символов в текстах и условиях.
- Ударения в словах, где книга их печатает (сто́ит, зна́ком, писа́ть, самому́, расцве́ли, При́став): восстановлены по скану.
- Сноски (¹ ² ³ ⁴): восстановлены по скану, текст сносок хранится вместе с текстом.
