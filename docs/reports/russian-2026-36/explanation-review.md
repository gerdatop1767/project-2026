# Объяснения и подсказки — что проверить (2026)

Объяснения и подсказки написаны для проекта в стиле существующих заданий: правило, разбор каждого варианта, «Ответ: …». Официальных объяснений в книге нет. Есть у всех 971 задания (проверено на стенде).

Задание 27: проблема и позиция автора взяты из раздела учебника «Информация о текстах» (PDF 333–338), добавлены критерии оценивания. Пример сочинения написан для проекта и помечен так в первой строке: «Это один из возможных примеров… Он написан специально для этого задания». Образцовых сочинений в книге нет.
