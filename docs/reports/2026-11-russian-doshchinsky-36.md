## Что сделано

- **Схема.** Единственное расширение — колонка `tasks.accepted_answers` (`text[]`, миграция 0038). Проверка ответа в API принимает основной ответ или любую альтернативу, с тем же режимом «любой порядок».
- **Данные.** `packages/db/src/russianDoshchinsky36/variant01.ts` … `variant36.ts`: тексты A/B, условия, ключи, объяснения и подсказки по каждому типу задания.
  - Тексты взяты из OCR. Повреждённые места сверены со сканами PDF.
  - Ответы взяты из архива ответов, сверены с ключом книги.
- **Импортёр.** `importRussianDoshchinsky2027Book36.ts` создаёт отдельную коллекцию `ege-2027-doshchinskiy-russian-36` (36 вариантов).
  - Повторный запуск идемпотентен (upsert).
  - Источник, вариант и страница сохраняются в каждом задании.
  - Задание с пометкой `sameAs` не копируется: в вариант привязывается уже существующая строка.
- **Проверка дублей.** Сравнение идёт с 18 вариантами Дощинского, которые уже есть в боте, и между вариантами книги.
  - Совпадений с ботом нет.
  - Внутри книги найдены 2 дословных повтора, они не задублированы.
  - Частичные совпадения (В8/В22 №14, В11/В26 №14, В13/В29 №14, В14/В30 №14 — общие 2–3 предложения из 5) — разные задания с разными ответами. Они оставлены.
- **Тесты** (`importRussianDoshchinsky2027Book36.test.ts`, 9 шт.):
  - 26 заданий в каждом варианте, объяснение и подсказка у каждого;
  - формат ответа соответствует номеру задания;
  - каждая альтернатива проходит настоящий `checkAnswer`;
