# Аудит поля ответа и показа ответов (06.11.2026)

Правильные ответы в базе не менялись. Изменились только вёрстка и то, где строка может переноситься при показе.

## Что проверено

- **Ответы.** Все 1137 опубликованных заданий с ответом из базы стенда: математика — 678, русский — 459. Сочинения (18 заданий) без ответа не проверялись. Для заданий из частей («а/б/в») проверена каждая часть отдельно.
- **Типы ответов:**
  - целые, отрицательные и десятичные (`-0,75`) числа;
  - дроби (`30067/3661`);
  - корни, степени, π;
  - списки корней №13 (до шести значений);
  - объединения интервалов №15/№18 — до 219 символов, с `arccos`, `\dfrac`, `\left…\right`;
  - ответы с параметром (`a∈…, a≠…`);
  - слова (русский язык);
  - многочастные ответы.
- **Места показа.** Для каждого ответа проверено каждое место, где он виден:
  - поле ввода (`MathAnswerField`);
  - «Твой ответ» и «Правильный ответ» на мобильном экране результата;
  - эти же блоки на десктопе;
  - строка итога в боковой панели;
  - ответы в разборе попытки варианта.
- **Ширины:** 320, 390 и 1440 px.
- **Метод.** Реальные компоненты и их CSS-модули во временном стенде (в репозиторий не входит). Для каждого места измерено:
  - выход за карточку;
  - скрытый текст в поле;
  - прокрутка внутри формулы;
  - ошибки KaTeX;
  - горизонтальная прокрутка страницы.
- **Живая проверка** в production-сборке: гостем через задание №18 с самым длинным ответом на 320, 390 и 1440 px.

## Что было

| Проблема | Где | Сколько (390 px) |
|---|---|---|
| Ответ выходит за карточку или растягивает страницу | `.answerBox` / `.answerValue` — flex без `min-width: 0`; формула ответа распадалась на отдельные flex-элементы с `space-between` | 102 правильных ответа; 43 введённых; страница прокручивалась вбок |
| Длинный ответ в однострочном поле виден не целиком | `<input>` | 47 ответов (№13, №15, №18, №19) |
| Длинная формула ответа читается только прокруткой | одна KaTeX-формула без переносов | 26 ответов шире строки на 20–290 px |
| Строка «Правильный ответ» в боковой панели без переноса | `.resultRow` | длинные ответы |

## Что сделано

- **Поле ответа — авторастущий `<textarea rows=1>`.**
  - Одна строка — та же высота 2,75rem, что у прежнего поля; длинный ответ переносится и виден весь.
  - Enter строку не добавляет, переносы во вставленном тексте заменяются пробелами — ответ остаётся одной строкой.
  - Автокоррекция и проверка орфографии выключены.
- **Блоки ответа.**
  - Ответ обёрнут в один текстовый блок `.answerText` с `min-width: 0` и `overflow-wrap: anywhere`.
  - Иконка ✓/✗ не сжимается.
  - То же сделано для десктопных `.answerValue`, строки итога и ответов в разборе попытки.
- **`AnswerMathText`** — только для показа ответов, не для условий и решений.
  - Формула режется на верхнем уровне: перед `∪` и после разделяющих `,` / `;`. Внутри скобок, `\left…\right`, дробей и фигурных скобок разреза нет.
  - Каждый кусок остаётся целой формулой (правило проекта: формула не разрывается), строка переносится между кусками.
  - Символы и порядок те же; команда отступа после разделителя заменяется обычным пробелом.
- **Исправление по ходу.** Первая версия разбиения оставляла `\` в конце куска (`;\ ` → `;\`), и формула выводилась красной ошибкой KaTeX. Ошибка найдена на живой проверке. Добавлен тест: каждый кусок — корректный LaTeX.

## Результат (те же 1137 ответов)

| | 320 px | 390 px | 1440 px |
|---|---|---|---|
| Выход за карточку | 0 | 0 | 0 |
| Скрытый текст в поле | 0 | 0 | 0 |
| Горизонтальная прокрутка страницы | нет | нет | нет |
| Ошибки KaTeX | 0 | 0 | 0 |
| Формула шире строки более чем на 4 px | 0 | 0 | 0 |

Осталось 16–18 мест, где формула шире своего блока на 1–4 px. Это выступ глифа KaTeX (например, у знака корня), не обрезка: формула лежит в своём прокручиваемом блоке, и подсказка прокрутки при таком выступе не показывается (`SCROLL_SLACK_PX`).
