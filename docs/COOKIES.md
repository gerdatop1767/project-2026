# Cookies и согласие

Что сайт хранит в браузере. Проверено по коду; если что-то добавляется, этот файл и текст баннера (`apps/web/src/ui/CookieBanner`) нужно обновить вместе с политикой (`apps/web/src/data/siteInfo.ts`).

| Где | Что | Категория | Срок |
|---|---|---|---|
| cookie `session_id` (httpOnly) | вход в аккаунт | необходимые | 30 дней |
| cookie `zc` | выбор по cookie: `a1` — аналитика разрешена, `a0` — отклонена | необходимые | 1 год |
| cookie `zv` (httpOnly) | случайный id браузера для собственной статистики | **аналитика — только с согласия** | до 400 дней |
| cookie Яндекс.Метрики (`_ym_uid`, `_ym_d`, `_ym_isad`, `_ym_visorc` и др.) | счётчик 114059780 с Вебвизором, ставит Яндекс | **аналитика — только с согласия** | по правилам Яндекса, до 1 года |
| localStorage | тема, копия выбора по cookie, скрытие кнопки Telegram на сутки, прочие настройки интерфейса | необходимые | — |

Рекламы на сайте нет — категория «Реклама» в баннере честно помечена «Не используется»; фиктивно её не включаем.

## Как работает

- **Баннер** (`ui/CookieBanner`): «Принять», «Отклонить необязательные», «Подробнее» (категории). Решение пишется в `zc` (и копией в localStorage) и больше не спрашивается. Если хранилище недоступно, выбор действует до перезагрузки — сайт работает.
- **Изменить выбор:** кнопка «Изменить настройки cookie» внизу `/privacy`.
- **Клиент** (`lib/analytics.ts`): пока нет `zc=a1`, события не копятся и не отправляются. После «Отклонить» очередь сбрасывается и вызывается `DELETE /api/v1/events/visitor` — сервер удаляет `zv`.
- **Сервер** (`apps/api/src/modules/analytics`):
  - без `zc=a1` `POST /events` ничего не записывает и `zv` не ставит;
  - ссылки кампаний `/go/:slug` без согласия считают клик анонимно — без `zv` и без последующей атрибуции регистрации;
  - `readVisitorId` без согласия возвращает `null`.
- **Яндекс.Метрика** (`index.html`, `lib/metrika.ts`): код счётчика не загружается, пока нет `a1`. При `a1` стартует на загрузке, при «Принять» — сразу в той же странице; повторный старт — no-op. После «Отклонить» на уже открытой странице счётчик доработает до перезагрузки (выгрузить чужой скрипт нельзя), со следующей загрузки не стартует. Cookie `_ym_*` ставит Яндекс, удалить их со своего домена сайт может только при следующем визите — не делаем этого вслепую.
- **Cookie сессии** согласием не управляются.

## Следствие для статистики админки

Посетители, отклонившие аналитику, не попадают в «визиты» и воронки по посетителям. Клики по кампаниям без согласия считаются, но без привязки к регистрации. Данные по аккаунтам (ответы, XP, ошибки) от согласия не зависят: это работа сервиса, а не аналитика.

## Юридически

Баннер не заменяет политику обработки персональных данных и согласие на неё. Текст политики (`/privacy`) остаётся черновиком с отмеченными местами `[Заполнить: …]`: оператор, контакты, хостинг. Их должен заполнить владелец; при необходимости стоит согласовать текст с юристом.
