**Ограничение.** Оригинальных PDF 2026 в среде нет: `variant6_10.pdf`, архивы `variant*_text_images.zip` и PDF вариантов 2–5. Поэтому «есть ли рисунок в источнике» определено по трём признакам:

- по отметкам импорта `[график: …]` / `[рисунок]` в `rawStatement`;
- по манифестам и отчётам импорта (`hasImage`, раздел «Images»).

Каждая строка ниже требует сверки с оригиналом перед добавлением рисунка.

Теперь SVG показываются только у заданий В1. У остальных показывается собственный `imageUrl`. Если файла нет, а условие ссылается на рисунок, показывается пометка «Рисунок к этому заданию ещё не добавлен». Чужой рисунок не показывается нигде.

### Как добавить, когда файлы будут

Тем же способом, что для 2027 (`docs/imports/ege-2027-yashchenko-v1-v2-report.md`):
1. Вырезать фрагмент страницы целиком — оси, подписи, точки, стрелки — без перерисовки.
2. Положить файл в `apps/web/public/tasks/imports/ege-2026-variant-N/task-NN-….png`.
3. Указать `imageUrl` у этого задания в `importEge2026VariantN.ts`. Текст условия и ответ не менять.
4. Сверить рисунок с уже записанным ответом: ответы этих заданий считаны по тем же рисункам при импорте.
5. Убрать задание из `KNOWN_MISSING` в `packages/db/src/ege2026Figures.test.ts`.

Тест проверяет три вещи:
- рисунок лежит в папке своего варианта и назван своим номером;
- файл существует;
- одна и та же картинка не используется двумя заданиями.

Чужой рисунок или повторно использованный файл тест не пропустит.

До этой ветки на сайте у этих заданий показывались SVG Варианта 1. Это были не их рисунки, а чужие, и они противоречили условию. Например:

Возможный вариант, требующий отдельного решения владельца:
- **Задания №2 (векторы).** В импортёрах записаны координаты концов векторов, считанные с оригинала по сетке. По ним можно построить точный SVG тем же компонентом `CoordinatePlaneSVG`. Но это реконструкция, а не исходный рисунок. Без оригинала нельзя проверить, совпадают ли с ним область сетки и подписи.
- **Задания №8 и №11 (графики).** Для графиков записано только словесное описание, по нему точно восстановить кривую нельзя.
