## Источник

«ЕГЭ 2026. Математика. Профильный уровень. Типовые экзаменационные варианты» (под ред. И. В. Ященко).
- Файл PDF «первые 20 вариантов»: 84 страницы, sha256 `09310566cfa06b31885e24110ef17b8cb23049b3668637f78ec72ccc348cf95b`.
- Это то же издание, что и у импорта: тексты заданий на страницах дословно совпадают с записанными, например В8 №7, №9, №10.
- Вариант N занимает страницы PDF с 4N−2 по 4N+1.
- PDF Ященко 2027 к этим заданиям не относится, и издания не смешивались.

## Как получены рисунки

- Каждая страница отрисована из PDF (`pdftoppm`, ~150 dpi по исходному масштабу; ширина страницы ≈ 4300 px).
- Фрагмент с рисунком вырезан целиком: сетка, оси, подписи «0», «1», «x», «y», стрелки, точки, пунктиры.
- Поля подрезаны по содержимому с отступом 14 px. Пиксели светлее 215 выставлены в белый, чтобы убрать фон бумаги. Больше никакой обработки.
- Рамка выбиралась так, чтобы не захватить текст условия, соседние задания и водяной знак. Каждый фрагмент просмотрен визуально.
- Перерисовки и SVG-реконструкций нет.

Каждый рисунок сверен с записанным ответом:
- точки и концы векторов определены по сетке;
- для графиков №8 знак и величина наклона в отмеченных точках измерены по пикселям: секущая по центральной линии кривой на ±13–20 px.
