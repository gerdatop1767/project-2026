## Как устроено

- **Данные:** `packages/db/src/zybrilkaRussian10/tasks.ts`. У каждого слова указано правило, по которому выбирается буква (`rules.ts`: З/С, неизменяемые приставки, ПРЕ-/ПРИ-, ПРА-/ПРО-, РАЗ-/РОЗ-, Ы/И после приставок, Ъ/Ь, словарные слова).
- **Сборка:** `build.ts` строит из данных условие, ответ и разбор.
  - Условие — та же инструкция, что у импортированных №10, плюс 5 рядов.
  - Ответ — ряды, где во всех трёх словах одна буква. Ответ вычисляется, а не пишется руками.
  - Разбор — каждое слово с правилом, вывод по каждому ряду, «Обрати внимание», «Ответ».
- **Валидация** перед записью: ровно 50 заданий, нумерация 1…50, 5 рядов по 3 слова, буква каждого слова проверяется по её правилу (например, З/С — по звонкости следующей буквы, Ъ — только перед е/ё/ю/я). Также проверяется, что нет повторов рядов и заданий, ответ из 2–4 цифр, одно слово встречается не больше 3 раз.
- **Однозначность:** у слов, которые с другой приставкой тоже существуют (прибежать/пробежать, обсудить/отсудить, преследовать/проследовать), в скобках дан решающий контекст — так же, как в экзаменационных заданиях.
- **Импорт:** `packages/db/src/importZybrilkaRussian10.ts`. Запускается в цепочке `sync-content` после сборника Дощинского-2026 и перед словарём ударений.
  - Идемпотентен: ключ — (предмет, источник, номер задания в наборе 1…50).
  - Одна транзакция; ничего не удаляется; задания других источников не затрагиваются.
  - `content_hash` = sha256(`russian|источник|N|10|нормализованное условие`).
  - Задание с полем `review` импортируется как `needs_review` и скрыто от учеников.
- **Тесты:** `importZybrilkaRussian10.test.ts`. Проверяет данные, ответы (проверка в любом порядке), полноту разбора, отсутствие совпадений с рядами №10 обоих сборников «36 вариантов», навык, импорт, повторный запуск, неприкосновенность чужих заданий, `needs_review`.
- **Проверка на стенде** со всеми сборниками: ни один ряд не совпал ни с одним рядом существующих №10.

## Найдено попутно (не исправлялось)

В разборе задания Дощинский ЕГЭ-2026 («36 вариантов»), вариант 16, №10, ряд 5 написано «иСдавна». Ответ задания (34) верный, ошибка только в тексте разбора. Правильно — «издавна» (перед звонким «д» — З). Существующие источники в этой задаче не менялись.

## Задания 51–100 (добор, этап 2)

Задания 51–100 сгенерированы (`zybrilkaRussian10/extra.ts`) только из слов заданий 1–50: у каждого слова уже есть правило, и `checkWord` проверяет по нему букву. Новое задание — это новая комбинация уже проверенных слов.
- Ряды не повторяют ряды заданий 1–50.
- Слово встречается не больше 6 раз на 100 заданий.
- «Обрати внимание» — по орфограмме слова-ловушки.
- Сложность 51–100: 15 / 18 / 17; вместе с 1–50 — 30 / 40 / 30.
- Задания 1–50 не изменились: повторный импорт показывает «unchanged».
