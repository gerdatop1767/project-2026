## Метод

`checkTask4Keys()` (`packages/db/src/stressDictionary/task4Keys.ts`) для каждого из 90 вариантов ответа берёт отмеченное слово и ищет его в официальном списке (ё = е, как допускает ФИПИ). Затем решает, верно ли стоит ударение.

**Как решаются омографы.** Слово «отзыв» решается по контексту варианта и пояснению из списка: «о книге» → «Отзыв», «посла» → «отзЫв». Это V7.3 и V10.1 «отзЫв (на книгу)»: в обоих ударение неверное.

**Если слово решить нельзя,** задание помечается `manual`. Таких нет: все 90 слов есть в списке.

**Ожидаемый ключ** — номера верных вариантов. Он сравнивается с ключом проекта без учёта порядка цифр.

Расхождение само по себе ошибкой не считалось:
- **Подтверждённая ошибка ключа** — разбор задания сам повторяет показанную форму и утверждает норму, которая противоречит списку. То есть слово перенесено верно, ошибся вывод ключа.
- **Ручная проверка** — разбор противоречит самому условию или не оценивает спорное слово. Тогда нельзя исключить, что в книге слово напечатано иначе, чем перенесено.
