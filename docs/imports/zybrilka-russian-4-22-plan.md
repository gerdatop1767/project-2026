# Зубрилка — собственный банк ЕГЭ по русскому, №4–22: план и техническая памятка

Рабочий документ этапа. Его задача — чтобы при работе пакетами не приходилось заново изучать репозиторий.

## 1. Цель
- По 50 авторских заданий на каждый номер 4–22, кроме №10: итого 900 новых заданий.
- №10 уже есть (`zybrilka-russian-10`, `importZybrilkaRussian10.ts`). Его код и данные не меняются.
- Задания — авторский материал Зубрилки. Не ФИПИ и не Дощинский.
- Литературные цитаты из чужих книг не используются: все предложения и тексты написаны для проекта.

## 2. Форматы номеров (по базе: 90 заданий на номер из трёх сборников; спецификация ЕГЭ-2027 = 2026)

| № | Что проверяет | Формат ответа в базе | Особенности |
|---|---|---|---|
| 4 | Ударение (орфоэпия) | цифры, порядок не важен (`digit_set_order_insensitive`) | 5 слов с выделенной гласной; ответ — верно выделенные. Слова — только из орфоэпического списка ФИПИ-2026 (`stressDictionary/data.ts`) |
| 5 | Паронимы | слово; `accepted_answers` при равноправных вариантах | 5 предложений, выделенное слово **ПРОПИСНЫМИ**, одно употреблено неверно; записать пароним в нужной форме |
| 6 | Лексические нормы | слово | Две формулировки: «исключив лишнее слово» (плеоназм, тавтология) или «заменив употреблённое неверно слово» (сочетаемость) |
| 7 | Морфологические нормы | слово | 5 выделенных форм, одна ошибочна; записать верную форму |
| 8 | Синтаксические нормы | `multi_part` А–Д, по одной цифре 1–9 | 5 типов ошибок, 9 предложений: 5 с ошибками, 4 верных |
| 9 | Корни | цифры, порядок не важен | 5 рядов по 3 слова, «во всех словах одного ряда» |
| 11 | Суффиксы (кроме Н/НН) | цифры, порядок не важен | 5 рядов по 2 слова, «в обоих словах» |
| 12 | Личные окончания глаголов, суффиксы причастий | цифры, порядок не важен | 5 рядов по 2 слова |
| 13 | НЕ/НИ со словами | цифры, порядок не важен | 5 предложений с (**НЕ**)**СЛОВО**; спрашивают СЛИТНО или РАЗДЕЛЬНО |
| 14 | Слитно / раздельно / дефис | цифры, порядок не важен | 5 предложений, в каждом 2 выделенных слова; спрашивают СЛИТНО / РАЗДЕЛЬНО / ЧЕРЕЗ ДЕФИС |
| 15 | Н и НН | цифры, порядок не важен | Текст с метками (1)…(N); спрашивают НН или «одна буква Н» |
| 16 | Однородные члены, ССП | цифры, порядок не важен | 5 предложений без знаков; ответ — где нужна ОДНА запятая |
| 17 | Обособленные члены | цифры, порядок не важен | Позиции (1)…(N) в предложении |
| 18 | Вводные слова, обращения | цифры, порядок не важен | Позиции (1)…(N), может быть диалог |
| 19 | СПП | цифры, порядок не важен | Позиции (1)…(N) |
| 20 | Сложное предложение с разными видами связи | цифры, порядок не важен | Позиции (1)…(N), союзы на стыке |
| 21 | Пунктуационный анализ | цифры, порядок не важен | Связный текст из 8–9 пронумерованных предложений; знак — запятая, тире или двоеточие |
| 22 | Средства выразительности | `multi_part` А–Д | 5 предложений или фрагментов, 9 названий средств |

**Навыки:** выводятся из (`subject`, `source`, `sourceYear` = 2027, `taskNumber`) через `examSkillsForTask` → `russian.NN-…`. Вручную `task_skills` не пишутся. Новых навыков и изменений `examSpecs.ts` не нужно.

**Темы** (`topics.slug`) — те же, что у сборников, например `russian-orthoepy` (№4), `russian-paronyms` (№5). Полный список в `zybrilkaRussian/numbers.ts`.

**Проверка ответа в тренажёре** (`apps/api/src/modules/tasks/service.ts`) уже есть и не меняется:
- `checkAnswer`: без учёта регистра, ё = е, лишние пробелы и точка в конце игнорируются;
- для цифр при флаге — порядок не важен;
- любой из `accepted_answers` засчитывается;
- `multi_part` проверяется по каждой части.

## 3. Структура источников
- **Одна коллекция на номер:** `zybrilka-russian-N` (N = 4…22, кроме 10), название «Зубрилка — авторские задания по русскому языку, №N», издатель «Зубрилка», год 2027.
- Свойства коллекции: `in_all_sources = true`, `exam_format = null` — это наборы, а не варианты экзамена, первичные баллы не считаются.
  - Поэтому фильтр по номеру в «Сборнике» показывает ровно один номер.
- **5 вариантов** «Зубрилка — №N, набор K» по 10 заданий, позиции 1–10.
- `tasks.source` = «Зубрилка. Авторские задания ЕГЭ по русскому языку, №N»; `source_variant` = номер задания 1–50 — стабильный ключ; тег `zybrilka-russian-bank`.
- `content_hash` = sha256(`russian|source|n|N|нормализованное условие`) — так же, как у №10.

## 4. Данные и сборка (`packages/db/src/zybrilkaRussian/`)
- Ответ **никогда не пишется руками**: он вычисляется из структуры задания. Разбор строится из той же структуры, поэтому не может подтверждать другой ответ.
- `types.ts` — общий вид собранного задания: условие, тип ответа, ответ, допустимые ответы, разбор, подсказка, сложность, `kind` (подтип внутри номера), `review`.
- `build/*.ts` — сборщик для каждой механики:
  - ряды с пропущенной буквой (9, 11, 12);
  - выделенные слова с одной ошибкой (5, 7);
  - позиции запятых (15, 17–20);
  - предложения (13, 14, 16);
  - соответствие (8, 22);
  - текст (21);
  - словарь ударений (4);
  - редактирование (6).
- `data/taskNN.ts` — содержимое номера, пакеты по 10 (`batch1` … `batch5`).

## 5. Проверки (`validate.ts`, тесты)
- **Общие:**
  - номер ЕГЭ;
  - тип ответа под номер;
  - ответ непустой и в формате номера: цифры 1–9 без повторов по возрастанию / слово кириллицей / 5 частей А–Д;
  - разбор ≥ 200 символов, заканчивается «Ответ: …» с тем же ответом;
  - подсказка есть;
  - номера 1…50 без пропусков;
  - нет повторов условий внутри банка и с №10;
  - `kind` — не меньше 3 разных на номер;
  - сложность 15 / 22 / 13 при 50 заданиях.
- **По механикам:**
  - №4 — каждое слово есть в словаре ФИПИ, верная гласная совпадает со словарём, неверная — гласная, не ударная ни в одной форме слова. Омографы исключены. Ответ — 2–4 цифры.
  - 5, 7 — ровно одно неверное выделенное слово; исправление отличается от исходного; выделенное слово есть в предложении.
  - 6 — заменяемое или лишнее слово встречается в предложении ровно один раз.
  - 8, 22 — 5 разных цифр 1–9; в №8 ровно 4 предложения без ошибки; в №22 9 разных названий.
  - Метки (k) идут подряд от 1; ответ не пуст.
  - Ряды: буква у каждого слова одна; ответ ≥ 1 ряда.
- **С базой (тест импорта и стенд):** повтор условия или ряда/предложения с уже существующими заданиями (сборники и №10) — ошибка.
- **Ответ и проверка:** каждый ответ прогоняется через настоящий `checkAnswer` или проверку `multi_part`: верный засчитывается, неверный нет, цифры — в любом порядке.

## 6. Импорт
- `importZybrilkaRussianBank.ts` — один импортёр на все номера 4–22, кроме 10.
  - Валидация до записи; одна транзакция; upsert по (subject, source, source_variant).
  - Ничего не удаляет и не трогает другие источники.
- В `sync-content` и в production Compose номер попадает только **полным** (50 заданий). Незавершённый номер импортирует лишь тест или стенд (`allowIncomplete`).
- Цепочка `infra/docker-compose.yml`: после `importZybrilkaRussian10.js`, перед словарём ударений.
- `infra/docker-compose.deploy.yml` в репозитории **не отслеживается**: он живёт только на VPS. Строку для него и команды ручного деплоя даёт `docs/DEPLOYMENT.md`.
