## Итог

**Официальный документ не получен. Сверка с ним не выполнена, полнота словаря не подтверждена.**

Нужный файл: «Орфоэпический список – 2026» (ФИПИ). На него ссылается навигатор самостоятельной подготовки ФИПИ к ЕГЭ-2026, раздел «Фонетика»: `https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/ru-1-fonetika.pdf`.

Почему не получен:
- **Среда разработки:** `doc.fipi.ru`, `fipi.ru`, `ege.fipi.ru`, `navigator.fipi.ru` блокирует сетевая политика (прокси отвечает 403 на CONNECT).
- **Сам ФИПИ** открыт только для российских IP (см. `docs/imports/fipi-parser-experiment-report.md`).
- **Локально:** PDF в репозитории и в среде нет.

**Чтобы завершить сверку**, нужен сам PDF «Орфоэпический список – 2026» (или навигатор с этим списком). Его можно положить в репозиторий, например `docs/sources/fipi-orthoepic-2026.pdf`, или открыть домены `doc.fipi.ru` / `fipi.ru` в настройках сети окружения (с учётом ограничения ФИПИ по IP).
