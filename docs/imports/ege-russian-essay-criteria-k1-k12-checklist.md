# Чек-лист критериев К1–К12 для проверки сочинения ЕГЭ (задание 27, русский язык)

**Статус документа: справочный чек-лист, НЕ реализация.** Автоматическое выставление баллов НЕ реализовано. `EssayNotGradableError`/`submitAttempt` (`apps/api/src/modules/tasks/service.ts`) НЕ изменены — сочинение по-прежнему не проверяется автоматически, задание 27 во всех вариантах остаётся `status: 'needs_review'`, `correctAnswer: ''`. Этот документ — только справочный материал (чек-лист для самопроверки / будущей ручной или LLM-ассистированной проверки), структура критериев взята из официальной методики ФИПИ для сочинения ЕГЭ по русскому языку (формат 2022+ с заменой прежнего К4).

## Как использовать этот документ

Это чек-лист, НЕ автоматический скрипт. Предназначен для:
1. Показа рядом с полем ввода сочинения как подсказки ученику («проверь сам по этим пунктам перед отправкой») — соответствует «уровню 1» плана, озвученного ранее (информационный, без автооценки).
2. Будущей ручной проверки сочинений человеком (учителем/модератором).
3. Возможной будущей LLM-ассистированной проверки («уровень 2» плана) — ТОЛЬКО после отдельного явного решения пользователя и создания калибровочного набора эталонных сочинений с официальными баллами.

## Общая структура: 12 критериев, максимум 25 баллов (формат с заменой К4 на коммуникативный К4, актуальный с 2022 года)

| К6 | Точность и выразительность речи | 2 |

| К8 | Соблюдение пунктуационных норм | 3 |
| К9 | Соблюдение языковых норм (грамматика) | 2 |
| К10 | Соблюдение речевых норм | 2 |
| К11 | Соблюдение этических норм | 1 |
| К12 | Соблюдение фактологической точности | 1 |

## Детальный чек-лист по каждому критерию

### К1 — Формулировка проблемы исходного текста (0-1 балл)
- [ ] Проблема сформулирована (а не просто названа тема текста).
- [ ] Проблема верно отражает содержание исходного текста (не подменена похожей, но другой проблемой).
- [ ] Формулировка не содержит фактических ошибок, связанных с пониманием проблемы.

**0 баллов**, если: проблема не сформулирована ИЛИ сформулирована неверно (искажает содержание текста) ИЛИ сформулирована через непонимание (например, проблема перепутана с темой).

### К2 — Комментарий к проблеме (0-5 баллов)
- [ ] Приведены ДВА примера-иллюстрации из прочитанного текста, важных для понимания проблемы.
- [ ] Каждый пример пояснён (не просто процитирован/пересказан, а объяснено его значение для проблемы).
- [ ] Указана и пояснена смысловая связь МЕЖДУ примерами (например: противопоставление, причина-следствие, дополнение, аналогия и т.п.) — без указания и пояснения связи максимум 4 балла из 5.
- [ ] Нет избыточного цитирования или простого пересказа без комментария.
- [ ] Нет фактических ошибок, связанных с пониманием исходного текста, в комментарии.

**Баллы:** 5 — оба примера приведены, пояснены, связь указана и пояснена, нет ошибок. 4 — связь указана, но не пояснена (или наоборот), либо 1 неточность. 3 — только 1 пример приведён и пояснён без связи, или оба примера без пояснений. 2 — примеры есть, но пояснения поверхностны/отсутствуют. 1 — 1 пример без пояснения. 0 — комментарий отсутствует, подменён пересказом всего текста, или не соответствует сформулированной проблеме.

### К3 — Отражение позиции автора (0-1 балл)
- [ ] Позиция автора по сформулированной в К1 проблеме чётко сформулирована.
- [ ] Позиция не искажает отношение автора к проблеме.

**0 баллов**, если позиция не сформулирована, сформулирована неверно, или не соответствует проблеме из К1.

### К4 — Отношение к позиции автора + обоснование (0-1 балл)
- [ ] Выражено согласие/несогласие с позицией автора ПО ПРОБЛЕМЕ ИСХОДНОГО ТЕКСТА.
- [ ] Отношение обосновано, с опорой на читательский, историко-культурный или жизненный опыт (НЕ повторяя суждений автора).
- [ ] Обоснование НЕ ссылается на источники из исключённого списка (комикс, аниме, манга, фанфик, графический роман, компьютерная игра — см. формулировку задания).

**0 баллов**, если отношение не выражено, или выражено без обоснования, или обоснование сводится к пересказу авторских суждений.

### К5 — Смысловая цельность, речевая связность, последовательность (0-2 балла)
- [ ] Сочинение характеризуется смысловой цельностью (нет логических разрывов, тема не теряется).
- [ ] Соблюдена последовательность изложения (введение → проблема → комментарий → позиция автора → своя позиция → вывод, не обязательно в этом точном порядке, но логично).
- [ ] Нет логических ошибок (нарушение причинно-следственных связей, необоснованные выводы).
- [ ] Нет неоправданных повторов мысли.
- [ ] Текст делится на абзацы в соответствии с его смысловой структурой.

**Баллы:** 2 — всё соблюдено, не более 1 логической ошибки. 1 — есть нарушения абзацного членения ИЛИ 1-2 логические ошибки. 0 — грубые нарушения смысловой цельности/последовательности.

### К6 — Точность и выразительность речи (0-2 балла)
- [ ] Используется разнообразная лексика (не только простейшие/повторяющиеся слова).
- [ ] Используются разнообразные синтаксические конструкции.
- [ ] Речь точна (слова употреблены в соответствии с их значением).
- [ ] Есть элементы выразительности речи там, где это уместно (не обязательное требование, но плюс).

**Баллы:** 2 — высокий уровень точности и выразительности. 1 — есть, но однообразие или отдельные неточности словоупотребления. 0 — бедность и однообразие грамматического строя речи, низкая точность.

### К7 — Орфографические нормы (0-3 балла)
- [ ] Подсчитать орфографические ошибки (не опечатки — именно нарушения правил написания).

**Баллы:** 3 — нет ошибок (или 1 негрубая). 2 — 1-2 ошибки. 1 — 3-4 ошибки. 0 — 5 и более ошибок.
*(Точные пороги могут уточняться методикой конкретного года — сверять с актуальными критериями ФИПИ перед использованием для реальной оценки.)*

### К8 — Пунктуационные нормы (0-3 балла)
- [ ] Подсчитать пунктуационные ошибки.

**Баллы:** 3 — нет ошибок (или 1 негрубая). 2 — 1-3 ошибки. 1 — 4-5 ошибок. 0 — 6 и более ошибок.
*(Пороги аналогично уточнять по актуальной методике года.)*

### К9 — Языковые нормы / грамматика (0-2 балла)
- [ ] Нет грамматических ошибок (согласование, управление, образование форм слова, построение предложений).

**Баллы:** 2 — нет ошибок. 1 — 1-2 ошибки. 0 — 3 и более ошибок.

### К10 — Речевые нормы (0-2 балла)
- [ ] Нет речевых ошибок (неверное словоупотребление, плеоназмы, тавтология, нарушение лексической сочетаемости — то же, что проверяется в заданиях 5-6 части теста).

**Баллы:** 2 — нет ошибок (или 1). 1 — 2-3 ошибки. 0 — 4 и более ошибок.

### К11 — Этические нормы (0-1 балл)
- [ ] Нет этических ошибок (некорректные высказывания, оскорбительные выражения, разжигание розни и т.п.).

**0 баллов** при наличии хотя бы одной этической ошибки.

### К12 — Фактологическая точность (0-1 балл)
- [ ] Нет фактических ошибок, связанных с понимание текста ИЛИ с привлечением фоновых знаний (исторических, культурных, литературных и т.п. фактов в обосновании К4).

**0 баллов** при наличии хотя бы одной фактической ошибки.

## Дополнительные формальные требования (проверяются ДО применения критериев)

- [ ] Объём — не менее 150 слов (при 70-149 словах — баллы по К7-К10 не выставляются / засчитываются особым образом; при менее 70 словах — сочинение не оценивается).
- [ ] Сочинение написано по ДАННОМУ тексту, не является пересказом исходного текста без комментариев (в этом случае — 0 баллов по всем критериям, кроме К7-К12, где проверяется грамотность, но итоговая оценка — 0 за содержательную часть, согласно формулировке задания: «Если сочинение представляет собой полностью переписанный или пересказанный исходный текст без каких бы то ни было комментариев, такая работа оценивается 0 баллов»).

## Ограничения этого документа

1. **Не заменяет официальную методику ФИПИ текущего года** — критерии и пороговые значения ошибок могут уточняться ФИПИ год от года; перед использованием для реальной оценки (особенно уровень 2 — автоматизированная LLM-проверка) сверить с актуальным документом «Критерии оценивания выполнения задания с развёрнутым ответом» на сайте ФИПИ.
2. **Не содержит калибровочных примеров** — для уровня 2 (LLM-ассистированная оценка) потребуется отдельный набор эталонных сочинений с официально выставленными баллами, которого в этой сессии нет и не создавался.
3. **Границы К7-К10 (количество ошибок → баллы) даны ориентировочно** — основаны на общеизвестной структуре критериев, но ТОЧНЫЕ пороги желательно перепроверить по официальному документу перед практическим использованием, а не полагаться на память этого чек-листа.
