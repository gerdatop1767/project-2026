# ZYBRILKA Content Studio: TikTok-ролики с Зубром

Студия собирает вертикальные ролики 1080×1920 **кодом**: Python, Pillow, OpenCV и ffmpeg. Платные генераторы и подписки не нужны. Ведущий — утверждённый маскот-зубр из `apps/web/public/branding/v3`. Его внешность не перерисовывается, а анимируется.

```
idea → script (voiceover.json) → TTS → word timings → storyboard (build.py) → rig + lip-sync → montage → mix → QC → MP4
```

## 1. Инструменты: что проверено и что выбрано

| Инструмент | Статус | Решение |
|---|---|---|
| **Higgsfield MCP** (видео Seedance/Kling, TTS ElevenLabs/MiniMax, lip-sync, image-to-video) | Подключён. Тариф starter, **10 кредитов**, бесплатного безлимита нет (`unlim.available=false`) | Сейчас не используется: на 10 кредитов не хватит даже одного ролика. Это апгрейд «на потом» (см. §7) |
| **Fish Audio API**, модель `s2.1-pro-free`, голос «Игровой Рассказчик» | Ключ в Network secrets, модель бесплатная | **Голос Зубра** (`tools/tts_fish.py`) |
| **Piper TTS** (MIT) + `ru_RU-dmitri-medium` (CC0) | Офлайн, бесплатно | Резервный голос (`tools/tts.py`) |
| Piper `ru_RU-denis-medium` (CC0) | Работает, но по ASR-тесту хуже разборчивость | Запасной голос |
| Piper `ru_RU-ruslan` | Лицензия CC BY-NC-SA | ❌ Нельзя: реклама — коммерческое использование |
| Silero TTS | Лицензия некоммерческая | ❌ |
| Edge TTS (Microsoft) | Неофициальный API, непрозрачные условия | ❌ |
| **faster-whisper** (MIT, модель small) | Работает на CPU | Автопроверка озвучки: распознаём текст обратно и ловим кривые ударения и слова |
| **OpenCV EDSR ×2** | Работает | Апскейл маскота 560→1120 px без потери чёткости |
| **Playwright + Chromium** | Работает | Скриншоты **настоящего** zybrilka.ru в мобильном вьюпорте (3×) |
| **ffmpeg** (libx264, aac, loudnorm, sidechain) | Работает | Кодирование, сведение, громкость −14 LUFS |
| Шрифт **Unbounded** (OFL) + Inter | Unbounded — тот же шрифт, что на сайте | Типографика роликов |
| Adobe / Canva / отдельный AI Voice Generator | Таких MCP или Skills в сессии **нет** | Не используются, всё закрыто кодом |
| Wav2Lip / SadTalker | Нужны GPU и PyTorch, рассчитаны на человеческие лица | Не подходят мультяшному зубру. Вместо них — свой риг (§3) |

Музыка и SFX синтезируются кодом (`tools/audio_fx.py`), поэтому авторских прав третьих лиц в них нет.

## 3. Как это работает

**Персонаж.** `tools/bison_rig.py` берёт утверждённый арт (`character/references/bison-front-thumbsup@2x.png`) и:
- сгибает челюсть: деформирует область под линией улыбки через `cv2.remap`;
- рисует полость рта, язык и верхние зубы при широких гласных;
- моргает: веко текстурировано цветом меха и повёрнуто по наклону головы.

Новый зубр не генерируется, поэтому внешность одинакова во всех роликах по определению.

**Lip-sync.** `studio.mouth_track()` идёт по озвучке кадр за кадром:
- громкость (RMS) задаёт открытие челюсти: быстрая атака, мягкий спад;
- спектральный центроид задаёт округлость губ («о», «у» — уже, «а», «э» — шире);
- губы опережают звук на 30 мс, как в анимации.

Кивки и наклон головы привязаны к энергии речи.

**Голос.** `tools/tts.py` синтезирует каждую реплику из `voiceover.json`:
- фиксированный голос и параметры;
- ударения ставятся знаком `´` (Зубри́лка) или фонемами `[[ … ]]`;
- паузы задаются полем `pause_after`;
- обработка: EQ, компрессия, −14 LUFS.

Скрипт сохраняет таймкоды реплик (`lines.json`). Из них считаются таймкоды слов для субтитров и привязки событий.

**Монтаж.** В `studio.py` лежат фон (бренд-градиент и плавающие формулы), мокап телефона, выноски-увеличения реальных экранов, бейджи, иконки, karaoke-субтитры и энкодер. `build.py` конкретного ролика — это раскадровка в коде: сцена → слово → событие. Все события звучат ровно на нужном слове.

**Сведение.** Музыка приглушается под голосом (sidechain), SFX ставятся по событиям. Финал: H.264 + AAC, `+faststart`.

## 4. Как сделать новый ролик

```bash
cp -r videos/001-what-is-zybrilka videos/002-<slug>    # затем удалить final/ audio/ render/
# 1) правим voiceover.json (текст по шаблону scripts/TEMPLATE-script.md)
python3 tools/tts.py videos/002-<slug>                  # озвучка + таймкоды
# 2) ASR-проверка ударений (см. character/voice/VOICE.md), правим ´ и [[ ]]
# 3) скриншоты сайта: node videos/001-what-is-zybrilka/capture.js (+ capture-task.js для сценария задания) <out_dir>
python3 videos/002-<slug>/build.py --preview 1.5,8,20   # стоп-кадры, проверить композицию
python3 videos/002-<slug>/build.py                      # полный рендер (~3,5 мин на 30 с, CPU)
```

Первичная установка в новой сессии: `pip install piper-tts faster-whisper opencv-contrib-python-headless`, затем скачать модели голоса (VOICE.md). В окружении должны быть разрешены хосты `zybrilka.ru`, `huggingface.co` и `us.aws.cdn.hf.co`.

## 5. Экономика

| Статья | Стоимость |

Учёт ведётся в `analytics/cost-ledger.csv`.

## 6. Контроль качества

Чек-лист: `analytics/qc-checklist.md`. Автоматически проверяются:
- ASR-распознавание финального MP4;
- громкость EBU R128;
- параметры потока через ffprobe;
- стоп-кадры lip-sync.

## 7. Масштабирование

- **3–5 роликов в неделю.** Шаблонная сцена «телефон + выноска», «крупный план» и CTA уже есть. Новый ролик — это новый `voiceover.json`, новые скриншоты и 30–60 строк таймлайна.
- **Следующие шаги по качеству:**
  - Нарезать арт на слои (голова, тело, рука) для настоящих жестов. Сейчас тело движется целиком.
  - Добавить вторую позу-референс (`bison-welcome`) под риг.
  - Разметить фонемы (Piper выдаёт фонемы) для визем точнее, чем по громкости.
  - Кривая энергии в TTS: темп по фразам.
- **Платный апгрейд, если появится бюджет.** Higgsfield:
  - Seedance 2.0 с референсами зубра для живых «кинематографичных» вставок 3–5 с;
  - TTS ElevenLabs с сохранённым Voice ID для более эмоционального голоса.

  Конвейер не меняется, меняются только источники кадров и звука.
- **Аналитика TikTok.** Раз в неделю заносить в `analytics/` удержание на 3 с, досмотры, переходы. Хуки с лучшим удержанием на 3 с переиспользовать как формулу. Рубрики, которые не набирают досмотры, сокращать. Пропорция 40/25/20/15 — стартовая.
