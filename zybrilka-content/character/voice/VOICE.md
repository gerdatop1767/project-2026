**Не менять голос между роликами.** Голоса-клоны знаменитостей не использовать никогда.

## Как работает
- `python3 tools/tts_fish.py <video_dir>`: реплики из `voiceover.json`, каждая отдельным запросом.
- Кэш в `audio/fish_cache/`: повторный запуск не тратит лимит. Переозвучить одну реплику: `--force <id>`.
- Ключ API хранится в Network secrets окружения (хост `api.fish.audio`). Прокси подставляет его сам, в коде ключа нет.
- Платные модели (`s1` и др.) требуют пополнить API-баланс: fish.audio → Developers → Billing. Этот баланс отдельный от подписки.
