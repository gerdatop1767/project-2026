# Чек-лист перед экспортом

**Текст и факты**
- [ ] Хук — первые 1–3 с, без «Всем привет / Сегодня я расскажу»
- [ ] Все цифры и функции сайта сверены с живым zybrilka.ru (дата сверки в script.md)
- [ ] ЕГЭ-факты: номер задания, формат, критерии — по спецификации ФИПИ нужного года; свои советы помечены как советы
- [ ] Ответы в разборах пересчитаны

**Голос**
- [ ] Голос `ru_RU-dmitri-medium`, параметры из VOICE.md
- [ ] Фонемы проверены (ударения), ASR-обратная проверка без смысловых искажений
- [ ] Окончания не обрезаны, паузы естественные

**Картинка**
- [ ] Зубр = официальный арт, без артефактов рига (стоп-кадры рта, моргания)
- [ ] Lip-sync: рот закрыт в паузах, открывается на ударных слогах
- [ ] Интерфейс — только реальные скриншоты, без cookie-баннера и чужих данных
- [ ] Логотип/вордмарк без искажений
- [ ] Субтитры: без ошибок, в безопасной зоне (x 60–930, y 150–1440), синхронны речи

**Техника** (`ffprobe`, `ffmpeg -af ebur128`)
- [ ] 1080×1920, 9:16, H.264 yuv420p, 30 fps, AAC 48 кГц, `+faststart`
- [ ] Громкость −14 LUFS ±1, true peak ≤ −1 dBTP
- [ ] Длительность по рубрике (реклама 10–20 с, основные 15–35 с, объяснения 30–60 с)

**Публикация** — только после явного разрешения владельца.
