# Оркестратор: ZYBRILKA Content Run

Запускается по расписанию 2 раза в день, каждый раз в новой облачной сессии. Главный агент сам ролик не делает. Он ведёт 4 агента по очереди, решает спорные места, доставляет результат владельцу в Telegram и сохраняет всё в Git.

## 0. Подготовка (≤ 3 мин)
1. Репозиторий `gerdatop1767/project-2026` должен лежать в рабочей папке. Если его нет, подключи его через `add_repo` и склонируй.
2. `git fetch origin chore/add-emil-design-eng-skill && git checkout chore/add-emil-design-eng-skill && git merge --ff-only origin/chore/add-emil-design-eng-skill`. Инструменты студии и агенты живут в этой ветке.
3. Зависимости ставит setup-скрипт окружения. Если `python3 -c "import piper, faster_whisper, cv2"` падает, выполни `pip install piper-tts faster-whisper opencv-contrib-python-headless`.
4. `RUN_ID=$(TZ=Europe/Moscow date +%Y-%m-%d-%H%M)`, затем `mkdir -p zybrilka-content/runs/$RUN_ID`.

5. **Память тем:** `python3 zybrilka-content/tools/topics.py list > zybrilka-content/runs/$RUN_ID/used_topics.txt`. Это все уже сделанные ролики (хранятся в закреплённом сообщении Telegram, т.к. git-история в новой сессии может быть пустой). Передай этот файл исследователю и сценаристу как **запрет на повтор**. Номер ролика NNN = число строк в used_topics.txt + 1 (не по папкам videos/).

## 0b. Аналитика
Агент `zyb-analyst`, вход — папка запуска. Ожидается `analysis.md` со статистикой прошлых роликов, выводами и шаблоном описания для TikTok. Передай `analysis.md` исследователю и сценаристу как обязательное чтение.

## 1. Исследование
Агент `zyb-trend-researcher`, вход — папка запуска. Ожидается `brief.md` и `brief.json` с 5 идеями.

## 2. Сценарий и утверждение
Агент `zyb-scriptwriter`, вход — папка запуска. Ожидается папка ролика с `voiceover.json`, `storyboard.json`, `script.md`, озвучкой и пометкой `APPROVED`. Если не утверждено, вызови его ещё раз с указанием взять следующую идею (не больше 2 раз).

## 3. Производство
Агент `zyb-producer`, вход — путь к папке ролика. Ожидается `final/<slug>.mp4` и `qa/report.json`.

## 4. Контроль
Агент `zyb-qa`, вход — путь к папке ролика. Ожидается `qa/verdict.md`.
- Если ролик не прошёл QA за 2 цикла, **не шли владельцу «ролика нет»**: возьми следующую идею из брифа и сделай ролик заново (один раз). Текстовый отчёт о сбое — только если и вторая попытка не удалась.
- `REJECTED`: передай fix-лист `zyb-producer` (а если проблема в тексте или фактах — `zyb-scriptwriter`), затем снова `zyb-qa`. **Не больше 2 циклов правок.**
- После двух неудачных циклов ролик не отправляется как готовый. В Telegram уходит текстовый отчёт о проблеме (шаг 5b).

## 5. Доставка в Telegram
a) `APPROVED`. Перед отправкой допиши в `storyboard.json` объект `"telegram"`:
- `header` — первая строка: `🦬 <название> · рубрика · длительность`;
- `tiktok_description` — **готовое описание для TikTok** по шаблону из `analysis.md`: текст, эмодзи, хештеги, упоминание @Zybrilka_bot. Ровно этот текст опубликуется по кнопке, поэтому без служебных пометок и до 900 символов;
- `details` — подробное объяснение выбора (уходит отдельным сообщением после видео, до 4000 символов):
  - какие источники смотрел исследователь: форумы, Telegram-каналы, видео, новости — с примерами;
  - какие 3–5 идей были в финале и почему победила эта;
  - почему ролик должен зайти: хук, польза, неочевидность, актуальность; что учли из `analysis.md`;
  - какие факты проверены и по каким официальным источникам (URL);
  - какие позы зубра и экраны сайта использованы;
  - итоги QA: WER, синхронность рта, громкость, длительность.

Затем выполни `python3 zybrilka-content/tools/send_telegram.py <video_dir>`. **Сразу после успешной отправки** запиши тему в память: `python3 zybrilka-content/tools/topics.py add --title "<тема одной фразой>" --task "<предмет и номер задания, напр. рус 8>" --slug <NNN-slug>`. Без этого шага следующий запуск повторит тему. Видео уходит **файлом** (document) с кнопками «✅ Опубликовать в TikTok» и «❌ Не надо». Нажатия обрабатывает отдельная ежечасная задача (`tools/tiktok_api.py poll`). Сам ничего не публикуй.

b) Сбой на любом шаге: `python3 zybrilka-content/tools/send_telegram.py --text "⚠️ Зубрилка-студия <RUN_ID>: <что сломалось, на каком шаге, что нужно от владельца>"`.

Если Telegram недоступен (нет токена или chat id), всё равно доведи ролик до конца, закоммить и напиши это в итоговом ответе сессии.

## 6. Бэкап
1. `git add zybrilka-content .claude/agents`. Итоговые mp4 в Git не попадают (`.gitignore`), их копия — в Telegram. Всё, что нужно для перерендера, коммитится.
2. Коммит `feat(content): auto video <NNN-slug> (<RUN_ID>)`.
3. `git push origin chore/add-emil-design-eng-skill`. При сетевой ошибке повтори до 4 раз с паузой. Если на удалённой ветке есть новые коммиты — `git fetch` + `git merge`, без force.

## Правила
- **Модели:** все субагенты (аналитик, исследователь, сценарист, продюсер, QA) запускаются инструментом Agent с параметром **`model: "sonnet"`** (решение владельца 19.11.2026: экономия лимитов). Сам оркестратор работает на своей модели. Если агенты не зарегистрированы, запускай `general-purpose` с `model: "sonnet"` и передавай ему содержимое нужного `.md`.
- **Только предметы, которые есть на платформе (решение владельца 19.11.2026):** сейчас это **математика (профиль/база) и русский язык**. Предмет с 0 заданий на сайте (информатика, обществознание, английский, физика и т. д.) — тема запрещена, даже если очень трендовая. Список проверяй по `library/screens/SCREENS.md` → «Популярные предметы»; когда там появится новый предмет с заданиями, он станет доступен.
- **Темы не повторяются (решение владельца 19.11.2026, после трёх роликов подряд про «лишнюю цифру»).** Идея, совпадающая с used_topics.txt по сути (тот же приём/ловушка, даже другими словами), — запрещена. Тот же номер задания того же предмета — не чаще раза в 7 дней. Чередуй предметы и рубрики. Если исследователь вернул повтор — отправь его искать заново.
- Все агенты подчиняются `pipeline/CREATIVE_RULES.md`: ролик 12–25 с, небанальная полезная тема, разнообразие планов, поз и анимаций, сайт в кадре (мобилка — основа), без фото из интернета и без кодовых нарядов.
- CTA во всех новых роликах ведёт в Telegram-бота **@Zybrilka_bot**, а не на сайт (ролик 001 — исключение, не трогать).
- **Ничего не публиковать в TikTok.** Публикует только владелец.
- Голос и персонаж не менять (`character/voice/VOICE.md`, `character/CHARACTER.md`).
- Платные генерации запрещены. Fish Audio — только бесплатная модель из VOICE.md.
- Один запуск — один ролик. Итоговый ответ сессии: ссылка на папку ролика, вердикт QA, статус Telegram и push.
