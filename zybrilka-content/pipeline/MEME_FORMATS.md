# Мем-форматы, собранные из наших средств

| Формат | Как сделать в storyboard |
|---|---|
| **Ожидание / реальность** | Две сцены подряд. Сцена 1: зубр в довольной позе, светлый фирменный градиент, бейдж «Ожидание». Сцена 2: поза-реакция из `character/poses/library` или `pose:lying_books`, `transition: glitch`, бейдж «Реальность» |
| **POV: …** | Текст `typewriter` «POV: ты открыл задание 18» вверху, `closeup` или удивлённая поза из библиотеки, `zoom` переход |
| **Одобряю / не одобряю** | `left` с иконкой ✗ рядом с плохим способом, затем `right` (или поза из библиотеки) с ✓ рядом с хорошим |
| **Уровни сложности** | 3 карточки `card` с `anim: drop` подряд («Уровень 1 / 2 / 3: босс»), зубр в `corner`, на «боссе» — поза-реакция |
| **Тир-лист** | Карточка-таблица (S/A/B/C) из `card` с подсветкой `highlight`, слова появляются `slide_left` по очереди |
| **Таймлапс паники** | Короткие сцены по 1–1,5 с с `transition: glitch`, бейджи-часы «23:00 → 02:00 → 06:00», `pose:desk_night` в середине |
| **Миф / факт** | Бейдж «МИФ» (`style: red`, `anim: wiggle`) → бейдж «ФАКТ» (`style: green`, `anim: zoom`) + ссылка на ФИПИ в описании |
| **Найди ошибку** | `card` с задачей и ошибкой. Пауза в речи, затем `highlight` на ошибочной строке, `buzz` |
| **Когда…** | «Когда учитель сказал “это лёгкое”» — `pose:lying_books` на фирменном градиенте, без речи 1–2 с |

Правило: формат узнаваемый, но картинка своя. Никаких чужих кадров, лиц, логотипов и фото из интернета.
